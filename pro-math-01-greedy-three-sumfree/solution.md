## 2. 对所有 $`d\ge6`$ 的统一证明

### 2.1 证明目标与记号

设 $`A`$ 是一个候选集合，且它在 $`[1,2d-1]`$ 中恰好包含三个种子。要证明 $`A=S_d`$，只需验证：

1.  $`A`$ 中没有一个数是三个互不相同的 $`A`$ 中元素之和；
2.  每个 $`n>2d-1`$ 且 $`n\notin A`$ 的整数，都能表示成三个互不相同的 $`A`$ 中元素之和。

由于所有元素均为正数，第二项中的三个加数自动都小于 $`n`$。因此，这两个性质通过对 $`n`$ 的强归纳，完全确定了贪心数列。

固定 $`d\ge6`$，置

``` math
\begin{aligned}
M&=8d-3,\\
I&=[2d-1,3d-2],\\
J&=[2d-2,3d-3],\\
c&=4d-1,\\
E&=\{1,d-1,c\}\cup I,\\
T_q&=qM+J\qquad(q\ge1).
\end{aligned}
```

我们要证明的候选集合是

``` math
A=E\cup\bigcup_{q\ge1}T_q.
```

用 $`r^{\wedge}I`$ 表示 $`I`$ 中 $`r`$ 个**互不相同**元素的所有和。整数区间有一个基本性质：

``` math
r^{\wedge}[u,v]
=
\left[
ru+\frac{r(r-1)}2,\;
rv-\frac{r(r-1)}2
\right]
\quad\text{当 }v-u+1\ge r.
\tag{3}
```

例如，从最小的递增 $`r`$ 元组出发，每次将一个仍能增加的坐标增加 $`1`$，直至最大的递增 $`r`$ 元组，就依次取得两个端点之间的全部和。下面只用 $`r=2,3`$。

### 2.2 确定有限前缀，以及第一个周期块之前的全部空隙

最小的三个已有项之和为

``` math
1+(d-1)+(2d-1)=3d-1.
```

所以 $`[2d-1,3d-2]=I`$ 中的所有整数都会选入。

接着，

``` math
1+(d-1)+I=[3d-1,4d-2],
```

故这个区间中的所有数都被排除。

下一个数 $`c=4d-1`$ 必须选入。事实上，不使用 $`c`$ 的三项和：

- 如果只使用一个 $`I`$ 中元素，其和至多为 $`4d-2`$；
- 如果使用至少两个 $`I`$ 中元素，其和至少为
  ``` math
  1+(2d-1)+2d=4d.
  ```

所以 $`c`$ 无法表示。至此，数列的精确前缀就是 $`E`$。

再看 $`c`$ 之后的整数。由 (3)，有下表：

<div>

<div>

<div>

| 三项和的类型          | 恰好得到的整数区间 |
|-----------------------|--------------------|
| $`1+2^{\wedge}I`$     | $`[4d,6d-4]`$      |
| $`(d-1)+2^{\wedge}I`$ | $`[5d-2,7d-6]`$    |
| $`3^{\wedge}I`$       | $`[6d,9d-9]`$      |
| $`c+2^{\wedge}I`$     | $`[8d-2,10d-6]`$   |

</div>

</div>

<div>

</div>

</div>

当 $`d\ge6`$ 时，这四个区间相接或重叠，合起来覆盖

``` math
[4d,10d-6].
```

最后一处衔接正是

``` math
9d-9+1\ge8d-2
\quad\Longleftrightarrow\quad d\ge6.
```

另一方面，$`E`$ 中三个不同元素之和的最大值是

``` math
c+(3d-2)+(3d-3)=10d-6.
```

而第一个候选周期块的起点恰好为

``` math
\min T_1=M+(2d-2)=10d-5.
```

这就解释了公式 (1) 中有限前缀与第一个周期块之间的全部空隙。

### 2.3 所有候选周期块中的数都不可能被表示

定义

``` math
G=[3d-2,10d-6]
  =[\max J+1,\;M+\min J-1].
\tag{4}
```

因此，$`G`$ 模 $`M`$ 的剩余类恰好避开 $`J`$。

考虑任意三个不同的候选元素之和，其中至少有一个来自周期块。把所有周期块元素中的 $`qM`$ 部分减去，剩余的和满足：

<div>

<div>

<div>

| 来自周期块的元素个数 | 剩余的和所在区间 |
|----------------------|------------------|
| $`1`$                | $`[3d-2,10d-6]`$ |
| $`2`$                | $`[4d-3,10d-7]`$ |
| $`3`$                | $`[6d-6,9d-9]`$  |

</div>

</div>

<div>

</div>

</div>

第一行使用了 $`E`$ 中两个不同元素之和的界：

``` math
\min=d,\qquad \max=c+(3d-2)=7d-3.
```

第二、三行直接使用 $`J`$ 的端点和  
$`\min E=1,\max E=c`$。

这三个区间都包含在 $`G`$ 中，所以这种三项和的模 $`M`$ 剩余类不可能属于 $`J`$。它们因而不可能落进任何 $`T_q`$。

至于完全来自 $`E`$ 的三项和，其最大值为 $`10d-6<\min T_1`$，也不可能落进周期块。

结合前一节已经证明的前缀合法性，得到

``` math
A\cap 3^{\wedge}A=\varnothing.
\tag{5}
```

这里第二、三行的估计甚至允许剩余部分重复；这是对可能三项和的扩大，因此不会遗漏真正由三个不同元素产生的和。

### 2.4 两个相邻周期块之间的每个数都能表示

$`T_q`$ 与 $`T_{q+1}`$ 之间的空隙恰好为

``` math
qM+G.
```

我们只用 $`T_q`$ 中的一个元素和 $`E`$ 中两个不同的元素来覆盖这个空隙。减去 $`qM`$ 后，有：

<div>

<div>

<div>

| 三项和的类型      | 恰好得到的整数区间 |
|-------------------|--------------------|
| $`J+1+(d-1)`$     | $`[3d-2,4d-3]`$    |
| $`J+1+I`$         | $`[4d-2,6d-4]`$    |
| $`J+2^{\wedge}I`$ | $`[6d-3,9d-8]`$    |
| $`J+c+I`$         | $`[8d-4,10d-6]`$   |

</div>

</div>

<div>

</div>

</div>

前两处衔接完全相邻，最后两个区间重叠。因此它们覆盖整个

``` math
G=[3d-2,10d-6].
```

这些表示全部符合互不相同的要求：两个前缀元素彼此不同，而周期块元素严格大于所有前缀元素。

现在，所有 $`n>2d-1`$ 且 $`n\notin A`$ 的整数都已被覆盖：

- $`I`$ 与 $`c`$ 之间的空隙；
- $`c`$ 与 $`T_1`$ 之间的空隙；
- 每个 $`T_q`$ 与 $`T_{q+1}`$ 之间的空隙。

结合 (5) 和开头的贪心归纳判据，公式 (1) 得证。整个论证对每个 $`d\ge6`$ 同时成立。

## 4. 周期及预周期为什么是最小的

对 $`d\ge6`$，每个周期块包含 $`d`$ 个连续整数，故其内部有 $`d-1`$ 个差值 $`1`$。相邻两块之间的差值为

``` math
M-(d-1)=7d-2.
```

每 $`d`$ 个差值中，恰好有一个非 $`1`$ 的差值，因此最小差值周期长度就是 $`d`$。

相应的特征序列在每个模 $`M`$ 周期内，恰好有一段长度为 $`d`$ 的连续 $`1`$。任何最终周期都必须把这段连续 $`1`$ 的起点映到另一个起点，而这些起点之间的距离恰为 $`M`$ 的倍数。因此最小特征周期是

``` math
M=8d-3.
```

周期尾部之前恰有 $`|E|=d+3`$ 项，而进入第一块的那个差值是

``` math
(10d-5)-(4d-1)=6d-4.
```

它不等于周期向前延伸时应出现的 $`7d-2`$，所以差值预周期不能再缩短，恰为 $`d+3`$。

三个小参数的差值周期分别为

``` math
\begin{array}{c|l}
d&\text{重复的差值块}\\ \hline
3&(5)\\
4&(6,1,20)\\
5&(1,33,1,1,7,26,1,8,18,8).
\end{array}
```

每个块中最大差值都只出现一次，所以最小长度分别为 $`1,3,10`$。

其模 $`M`$ 的剩余类分别是

``` math
\begin{aligned}
R_3&=\{1\}\pmod5,\\
R_4&=\{2,8,9\}\pmod{27},\\
R_5&=\{10,11,12,19,45,46,54,72,80,81\}\pmod{104}.
\end{aligned}
```

每个剩余类圆周中，最长的连续选入段都只出现一次，因此最小特征周期分别为 $`5,27,104`$。

最后，进入各周期尾部的实际差值为

``` math
11-7=4,\qquad 29-15=14,\qquad 80-79=1,
```

而将相应周期向前延伸，应取的差值分别为 $`5,20,8`$。所以三个最小差值预周期长度恰为

``` math
|E_3|=5,\qquad |E_4|=7,\qquad |E_5|=13.
```

## 5. 为什么不可能得到原文所猜的模 $`8d-1`$ 描述

公式 (1) 还给出了对原模数断言的**无限族反证**。

固定任意 $`d\ge6`$，令 $`M=8d-3`$。对每个 $`q\ge1`$，周期块的末项

``` math
n_q=qM+3d-3
```

属于 $`S_d`$。但是

``` math
n_q+(8d-1)
=(q+1)M+3d-1
\notin S_d.
```

后者位于下一周期块末端之后。它也有显式的合法三项和表示：

``` math
(q+1)M+3d-1
=
1+(d-1)+\bigl((q+1)M+2d-1\bigr).
```

括号中的数属于下一周期块，三个加数互不相同。

由于 $`q`$ 可以任意大，**$`8d-1`$ 不可能是该特征序列的最终周期，无论允许多长的预周期。**

因此，题目要求证明的最终周期性已由 (1) 和三个有限证书覆盖全部 $`d\ge3`$；原 Conjecture 4 中的精确数值断言则应按第 1 节的表格修正。 $`\square`$
