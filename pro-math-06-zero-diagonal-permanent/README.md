# 五阶零对角双随机矩阵的积和式

我随手把这道题丢给了网页版 ChatGPT Pro。这里是保存下来的答复和核验材料。

## 题目

设 $`A`$ 是 $`5\times5`$ 非负实矩阵，各行各列之和均为 1，且对角线均为 0。是否总有 $`\operatorname{per}(A)\ge11/256`$，且等号仅当 $`A=(J-I)/4`$ 时取到？其中 $`J`$ 为全 1 矩阵，$`I`$ 为单位矩阵。

## 答复结果

五阶情形的最小积和式为 $`11/256`$，等号构型唯一。
