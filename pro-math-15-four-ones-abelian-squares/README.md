# 恰有四个 1 的二元串最少阿贝尔平方数

我随手把这道题丢给了网页版 ChatGPT Pro。这里是保存下来的答复和核验材料。

## 题目

对每个 n≥8，在长度 n、恰含四个 1 的二元串中，求不同阿贝尔平方子串的最少种数。阿贝尔平方由相邻且等长的两个非空块组成，两块中的 1 一样多。相同子串只计一次。

## 答复结果

最少种数为 $`\lfloor(n+2)/4\rfloor`$。
