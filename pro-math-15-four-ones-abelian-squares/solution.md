## 结论

记 $`M_4(n)`$ 为长度 $`n`$、恰含四个 $`1`$ 的二元串中，**不同阿贝尔平方子串**的最少种数。则

``` math

\boxed{\displaystyle M_4(n)=\left\lfloor\frac{n+2}{4}\right\rfloor
\qquad(n\ge8).}
```

下面给出达到该值的构造，以及覆盖全部 $`n\ge8`$ 的下界证明。证明会明确检查新增子串是否与此前计数重复。

**文献核对。** 原论文第 3 节定理 7 给出了两个 $`1`$ 的下界；第 5 节定理 12 的构造给出本题所需上界；第 6 节确实将四个 $`1`$ 包含在尚待解决的情形中。原文也明确区分了“不同子串”和“具有不同 Parikh 向量的子串”。本次检索没有找到专门证明这一四个 $`1`$ 精确下界的后续完整解答。以下把所用的两个 $`1`$ 引理也重新证明，使整个论证可以独立核验。[arxiv.org](https://arxiv.org/html/2604.23188v1)

## 一、达到上界的构造

令

``` math

z=n-4,\qquad
q=2\left\lfloor\frac{z+2}{4}\right\rfloor+1,\qquad
p=z-q.
```

因为 $`z\ge4`$，有

``` math

q\text{ 为奇数},\qquad q>p\ge1.
```

取

``` math

\boxed{w_n=1\,0^q\,111\,0^p.}
```

其长度为 $`n`$，恰含四个 $`1`$。逐类清点它的阿贝尔平方。

### 1. 含零个 $`1`$

最长零段长度是 $`q`$，所以恰有

``` math

00,\ 0^4,\ldots,0^{q-1},
```

共 $`(q-1)/2`$ 种。

### 2. 含两个 $`1`$

来自末端 $`111`$ 的两个相邻 $`1`$ 给出平方 $`11`$。若向两侧添加零，要使两半各含一个 $`1`$，添加的零数必须相等；但这对 $`1`$ 至少有一侧紧邻另一个 $`1`$，故只能取 $`11`$。

若因子包含最前面的孤立 $`1`$，另一枚 $`1`$ 必须是 $`111`$ 的第一枚，因子只能是

``` math

1\,0^q\,1.
```

它的长度 $`q+2`$ 为奇数，不是阿贝尔平方。

所以这一类只有 **$`11`$**。

### 3. 含四个 $`1`$

这样的因子只能是

``` math

1\,0^q\,111\,0^t,\qquad 0\le t\le p.
```

两半都必须含两个 $`1`$，所以切分只能为

``` math

(1\,0^q\,1)\mid(11\,0^t).
```

等长要求 $`q+2=t+2`$，即 $`t=q`$，与 $`t\le p<q`$ 矛盾。

因此

``` math

\theta(w_n)=\frac{q-1}{2}+1
=1+\left\lfloor\frac{n-2}{4}\right\rfloor
=\left\lfloor\frac{n+2}{4}\right\rfloor,
```

这里 $`\theta(w)`$ 表示 $`w`$ 中不同阿贝尔平方的种数。上界得到证明。

## 二、预备引理：恰含两个 $`1`$ 的串

**引理。** 对任意非负整数 $`A,B,C`$，

``` math

\boxed{\displaystyle
\theta(0^A1\,0^B1\,0^C)
\ge \left\lfloor\frac{A+B+C}{2}\right\rfloor.}
```

### 证明

先记录一个判据：

``` math

0^x1\,0^B1\,0^y
```

是阿贝尔平方，当且仅当

``` math

x+y\equiv B\pmod2,\qquad |x-y|\le B. \tag{1}
```

第一个条件保证总长度为偶数；第二个条件保证均分点位于两个 $`1`$ 之间。

反转不改变不同平方的种数，因此可设 $`A\ge C`$。记

``` math

H=\max(A,B),\qquad s=\min(A,B).
```

全零平方至少有 $`\lfloor H/2\rfloor`$ 种。再取所有

``` math

0^x1\,0^B1,\qquad
0\le x\le s,\quad x\equiv B\pmod2.
```

由 (1)，它们都是阿贝尔平方，至少有 $`\lceil s/2\rceil`$ 种。因此目前至少有

``` math

\left\lfloor\frac H2\right\rfloor
+\left\lceil\frac s2\right\rceil
\ge \left\lfloor\frac{A+B}{2}\right\rfloor
```

种。

接着，对每个 $`t=1,\ldots,C`$，取

``` math

0^{x_t}1\,0^B1\,0^t,
\qquad
x_t=
\begin{cases}
t,&B\text{ 为偶数},\\
t-1,&B\text{ 为奇数}.
\end{cases}
```

由于 $`A\ge C`$，这些因子都存在，且由 (1) 都是阿贝尔平方。

它们的尾零数分别为 $`1,\ldots,C`$，所以彼此不同，也与此前尾零数为零的两 $`1`$ 因子不同。故总数至少为

``` math

\left\lfloor\frac{A+B}{2}\right\rfloor+C
\ge
\left\lfloor\frac{A+B+C}{2}\right\rfloor.
```

引理得证。 $`\square`$

## 三、五个零间隔编码与下界证明

任取一个恰含四个 $`1`$ 的串，唯一写成

``` math

w=0^a1\,0^b1\,0^c1\,0^d1\,0^e,
\qquad a,b,c,d,e\ge0.
```

令

``` math

U=a+b,\qquad V=d+e.
```

反转后可设

``` math

U\ge V.
```

于是

``` math

n=U+V+c+4.
```

考虑只含前两个 $`1`$ 的前缀

``` math

P=0^a1\,0^b1\,0^c.
```

由引理，

``` math

\theta(P)\ge K,\qquad
K:=\left\lfloor\frac{U+c}{2}\right\rfloor. \tag{2}
```

这里有一个重要的去重依据：

> **$`P`$ 中每个含两个 $`1`$ 的因子，其两个 $`1`$ 之间都恰有 $`b`$ 个零。**

下面分中间两个 $`1`$ 是否相邻讨论。

### 情形一：$`c\ge1`$

由 $`U\ge V`$ 和 $`c\ge1`$，

``` math

n+2=U+V+c+6\le 2(U+c)+5.
```

利用对整数 $`h`$ 成立的恒等式

``` math

\left\lfloor\frac{2h+5}{4}\right\rfloor
=\left\lfloor\frac h2\right\rfloor+1,
```

得到

``` math

\left\lfloor\frac{n+2}{4}\right\rfloor\le K+1. \tag{3}
```

因此，只需证明 $`w`$ 至少有 $`K+1`$ 种平方。

#### 1. 若 $`d\ne b`$

使用最右边的两个 $`1`$。

- $`d`$ 为偶数时，取 $`1\,0^d1`$。
- $`d`$ 为奇数时，取 $`0\,1\,0^d1`$。所需的前导零来自 $`c\ge1`$。

由判据 (1)，它们都是阿贝尔平方。两个 $`1`$ 之间的零数为 $`d\ne b`$，所以这个因子不可能出现在 $`P`$ 中。

结合 (2)，有 $`\theta(w)\ge K+1`$。

#### 2. 若 $`d=b`$，且 $`c`$ 为偶数

令

``` math

X=1\,0^b1,\qquad c=2j.
```

包含四个 $`1`$ 的核心为

``` math

X\,0^{2j}\,X
=(X0^j)\mid(0^jX).
```

两半等长，各含两个 $`1`$，所以核心本身是阿贝尔平方。

它含四个 $`1`$，不可能是 $`P`$ 的因子，故又得到 $`\theta(w)\ge K+1`$。

#### 3. 若 $`d=b`$，$`c`$ 为奇数，且 $`a+e>0`$

写 $`c=2j+1`$，仍令 $`X=1\,0^b1`$。

若 $`a>0`$，在核心左端添加一个零，得到

``` math

0X0^{2j+1}X
=(0X0^j)\mid(0^{j+1}X).
```

若 $`e>0`$，在核心右端添加一个零，得到

``` math

X0^{2j+1}X0
=(X0^{j+1})\mid(0^jX0).
```

两种切分的左右半块均等长，且各含两个 $`1`$。因此至少得到一种含四个 $`1`$ 的新平方，仍有 $`\theta(w)\ge K+1`$。

#### 4. 剩余情形：$`d=b`$，$`c`$ 为奇数，且 $`a=e=0`$

若 $`b>0`$，中央两个 $`1`$ 给出因子

``` math

0\,1\,0^c1.
```

它由 (1) 是阿贝尔平方，所需的前导零由 $`b>0`$ 提供。

此时

``` math

P=1\,0^b1\,0^c.
```

由于 $`P`$ 以第一枚 $`1`$ 开头，并且仅有两个 $`1`$，**它的任何含两个 $`1`$ 的因子都必须以 $`1`$ 开头**。刚构造的因子以 $`0`$ 开头，因此是新的。

若 $`b=0`$，则

``` math

w=11\,0^c11.
```

它直接含有

``` math

\left\lfloor\frac c2\right\rfloor
```

种全零平方以及 $`11`$。此时 $`U=0`$，总数已达

``` math

\left\lfloor\frac c2\right\rfloor+1=K+1.
```

至此，所有 $`c\ge1`$ 的情形均已覆盖。结合 (3)，

``` math

\theta(w)\ge\left\lfloor\frac{n+2}{4}\right\rfloor.
```

### 情形二：$`c=0`$

此时中央两个 $`1`$ 相邻，且

``` math

K=\left\lfloor\frac U2\right\rfloor.
```

先只计含零个或两个 $`1`$ 的平方：

- 若 $`b>0`$，中央的 $`11`$ 不在 $`P`$ 中，与 $`P`$ 中至少 $`K`$ 种平方合计，至少有 $`K+1`$ 种。
- 若 $`b=0`$，则 $`P=0^a11`$，它自身就有 $`\lfloor a/2\rfloor`$ 种全零平方和 $`11`$，同样至少有 $`K+1`$ 种。

如果 $`U>V`$，则

``` math

n+2=U+V+6\le2U+5,
```

所以

``` math

\left\lfloor\frac{n+2}{4}\right\rfloor
\le \left\lfloor\frac U2\right\rfloor+1
=K+1.
```

下界已经成立。

最后考虑 $`U=V`$。此时整个串可以切分为

``` math

w=
\underbrace{(0^a1\,0^b1)}_{\text{长度 }U+2}
\mid
\underbrace{(1\,0^d1\,0^e)}_{\text{长度 }V+2}.
```

两半等长，并且各含两个 $`1`$。因此，**整个串本身是一个含四个 $`1`$ 的阿贝尔平方**，不同于此前计入的所有零 $`1`$ 或两 $`1`$ 平方。

故

``` math

\theta(w)\ge K+2
\ge
\left\lfloor\frac{2U+6}{4}\right\rfloor
=
\left\lfloor\frac{n+2}{4}\right\rfloor.
```

这就完成了所有五元组 $`(a,b,c,d,e)`$ 的下界证明。与第一节的构造相合，得到所述等式。 $`\square`$

这最后一步确有必要。例如

``` math

1000111000=(10001)(11000)
```

的不同阿贝尔平方恰为

``` math

00,\quad 11,\quad 1000111000.
```

只计含零个、两个 $`1`$ 的因子会少算一种。
