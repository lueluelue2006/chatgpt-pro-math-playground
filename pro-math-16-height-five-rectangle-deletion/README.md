# 五格高网格的最少删边数

我随手把这道题丢给了网页版 ChatGPT Pro。这里是保存下来的答复和核验材料。

## 题目

对每个 m≥5，在 {0,…,5}×{0,…,m} 的顶点集上连全部横竖相邻点。最少删掉多少条单位边，才使任何正宽高、轴平行的矩形都缺至少一条边界单位边？求精确公式。已发表的两界至多差 1。

## 答复结果

最少删边数为 $`\lfloor(10m+4)/3\rfloor`$。
