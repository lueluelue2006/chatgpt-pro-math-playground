## 精确答案

设所求最少删边数为 $`S(5,m)`$。则对每个 $`m\ge5`$，

``` math

\boxed{\displaystyle
S(5,m)=\left\lfloor\frac{10m+4}{3}\right\rfloor
=\left\lceil\frac{10m+2}{3}\right\rceil .}
```

按模 $`3`$ 分类，就是

``` math

\boxed{
\begin{aligned}
S(5,3k)&=10k+1,\\
S(5,3k+1)&=10k+4,\\
S(5,3k+2)&=10k+8.
\end{aligned}}
```

下面给出**上下界一致的完整手算证明**，以及题目要求的 **15 位有限状态递推和长期规律证书**。实际上，证明对所有 $`m\ge2`$ 都成立。

文献方面，我核对了 Niu、Tang 的 *On the rectangle eliminating number of grid graphs*，*Theoretical Computer Science* 1085 (2026), 116199。出版者公开页面中的 $`n\times m`$ 确实指 $`(n+1)`$ 行、$`(m+1)`$ 列顶点，与本题一致；页面明确说明 $`n=5`$ 的上下界至多差 $`1`$。公开预览未列出两个界的具体表达式。本次检索未找到可核实的后续完整公式；以下证明直接从原题出发。[sciencedirect.com](https://www.sciencedirect.com/science/article/pii/S0304397526004287)

## 一、下界：为什么至少要删这么多边

令

``` math

N=5m
```

为单位格的总数，设某个满足要求的方案删除了 $`d`$ 条边。

### 1. 用对偶连通分量记录删边

建立一个辅助图：

- 每个单位格对应一个顶点；
- 再增加一个代表网格外部的顶点 $`\Omega`$；
- 每删除一条网格边，就在它两侧的格子之间，或者在格子与 $`\Omega`$ 之间，加入一条辅助图的边。

所以辅助图有 $`N+1`$ 个顶点、$`d`$ 条边。边界处可能出现平行边，这不影响下面的论证。

我们需要一个基本观察：

> **若若干个不含 $`\Omega`$ 的完整连通分量，其单位格的并恰好是一个矩形，那么这个矩形的周界全部保留。**

原因是：如果周界上的某条边被删，那么它对应的辅助图边会把这个分量并集连接到补集，与“完整连通分量的并”矛盾。矩形贴着网格外框时，同样成立。

设含 $`\Omega`$ 的分量还包含 $`q`$ 个单位格，其余共有 $`c`$ 个分量，大小分别为

``` math

s_1,\ldots,s_c.
```

整个 $`5\times m`$ 网格的外围也是必须破坏的矩形，因此至少有一条外框边被删，故

``` math

q\ge1.
```

每个不含 $`\Omega`$ 的分量都至少包含三个格子。因为一个格子、两个共边相邻的格子，本身都是矩形，会违反基本观察。因此

``` math

s_i\ge3.
```

此外，恰有三个格子的分量只能是 **L 形三连块**：直排的三个格子也会形成周界完整的矩形。

于是

``` math

N-3c
=q+\sum_{i=1}^{c}(s_i-3)
\ge1.
\tag{1}
```

### 2. 关键端列引理：等号不可能成立

现在证明

``` math

N-3c=1
```

不可能。

如果等号成立，就必须同时满足：

- $`q=1`$；
- 其余所有分量都是 L 形三连块。

也就是说，整个 $`5\times m`$ 棋盘除去一个格子后，被这些 L 形分量铺满。

因为 $`m\ge2`$，左右两个端列至少有一个不含那个唯一的格子。选取这样的端列，它有五个格子，全部被 L 形块覆盖。

每个接触端列的 L 形块都伸入相邻列。设：

- 有 $`a`$ 块在端列占两个格子；
- 有 $`b`$ 块在端列占一个格子。

数端列的格子，得到

``` math

2a+b=5.
```

这些块分别在邻列占一个、两个格子，所以

``` math

a+2b\le5.
```

唯一的非负整数解是

``` math

a=2,\qquad b=1.
\tag{2}
```

记唯一在端列只占一格的块为 $`A`$。设它在端列占第 $`r`$ 格，在邻列占第 $`r`$ 和第 $`r+\varepsilon`$ 格，其中 $`\varepsilon\in\{-1,1\}`$。

端列第 $`r+\varepsilon`$ 格属于另一个块 $`B`$。由 (2)，$`B`$ 在端列占两格。它的另一格不能是已经被 $`A`$ 占据的第 $`r`$ 格，因此只能是第 $`r+2\varepsilon`$ 格。

而 $`B`$ 在邻列的一格也只能位于第 $`r+2\varepsilon`$ 格，因为第 $`r+\varepsilon`$ 格已被 $`A`$ 占据。

两块的布局被迫成为：

<div>

<div>

<div>

| 格行               | 端列  | 邻列  |
|--------------------|-------|-------|
| $`r`$              | $`A`$ | $`A`$ |
| $`r+\varepsilon`$  | $`B`$ | $`A`$ |
| $`r+2\varepsilon`$ | $`B`$ | $`B`$ |

</div>

</div>

<div>

</div>

</div>

因此，**这两个完整分量的并恰好是一个 $`3\times2`$ 矩形**。根据基本观察，其周界全部保留，矛盾。

所以 (1) 可以加强为

``` math

\boxed{N-3c\ge2.}
\tag{3}
```

这就是补上差 $`1`$ 的关键一步。

### 3. 从分量数得到删边数

辅助图有 $`N+1`$ 个顶点、$`c+1`$ 个连通分量。每个连通分量至少需要“顶点数减一”条边，所以

``` math

d\ge (N+1)-(c+1)=N-c.
```

结合 (3)，

``` math

\begin{aligned}
d
&\ge N-\left\lfloor\frac{N-2}{3}\right\rfloor\\
&=\left\lceil\frac{2N+2}{3}\right\rceil\\
&=\left\lceil\frac{10m+2}{3}\right\rceil.
\end{aligned}
```

因此

``` math

\boxed{\displaystyle
S(5,m)\ge\left\lceil\frac{10m+2}{3}\right\rceil.}
\tag{4}
```

这里没有假设原图连通，也没有假设辅助图是森林。

## 二、上界：一个明确的周期删边构造

下面给出达到 (4) 的构造。

### 1. 编号和操作表

把顶点行编号为 $`0,\ldots,5`$，顶点列编号为 $`0,\ldots,m`$。

从第 $`j-1`$ 列推进到第 $`j`$ 列时：

- 横边编号 $`r`$ 指 $`(r,j-1)(r,j)`$，其中 $`0\le r\le5`$；
- 第 $`j`$ 列的竖边编号 $`i`$ 指 $`(i,j)(i+1,j)`$，其中 $`0\le i\le4`$。

**先在第 $`0`$ 列删掉编号 $`4`$ 的竖边。**

之后采用以下六种操作。表中的集合都是要删除的编号，其余边保留。

<div>

<div>

<div>

| 操作  | 删除横边的行号 | 删除新列竖边的编号 | 删边数 |
|-------|----------------|--------------------|--------|
| $`A`$ | $`\{1,3\}`$    | $`\{0,3\}`$        | 4      |
| $`B`$ | $`\{2\}`$      | $`\{2,4\}`$        | 3      |
| $`C`$ | $`\{1,4\}`$    | $`\{0\}`$          | 3      |
| $`a`$ | $`\{2\}`$      | $`\{1,4\}`$        | 3      |
| $`b`$ | $`\{4\}`$      | $`\{0,2\}`$        | 3      |
| $`c`$ | $`\{1,3\}`$    | $`\{4\}`$          | 3      |

</div>

</div>

<div>

</div>

</div>

令 $`\rho`$ 表示上下反射：

- 横边编号 $`r\mapsto5-r`$；
- 竖边编号 $`i\mapsto4-i`$。

普通无限操作序列是

``` math

A\,B\,C\,\rho(A)\,\rho(B)\,\rho(C)\,
A\,B\,C\,\rho(A)\,\rho(B)\,\rho(C)\cdots.
\tag{5}
```

即三个操作以后上下反射，再重复。实际周期为六列，每六列删 $`20`$ 条边。

### 2. 三种余数如何截取

\*\*当 $`m=3k`$ 时：\*\*取 (5) 的前 $`m`$ 步。总删边数为

``` math

1+10k.
```

\*\*当 $`m=3k+2`$ 时：\*\*同样取前 $`m`$ 步。总删边数为

``` math

1+10k+4+3=10k+8.
```

\*\*当 $`m=3k+1`$、$`k\ge1`$ 时：\*\*先取前 $`m-3`$ 步。此时刚执行完 $`A`$ 或 $`\rho(A)`$：

- 若刚执行完 $`A`$，追加 $`a,b,c`$；
- 若刚执行完 $`\rho(A)`$，追加 $`\rho(a),\rho(b),\rho(c)`$。

总删边数为

``` math

1+10(k-1)+4+3+3+3=10k+4.
```

这些数量都等于

``` math

\left\lfloor\frac{10m+4}{3}\right\rfloor.
```

剩下只需证明这些操作确实破坏了所有矩形。

## 三、构造合法性的手算核验

这里使用题目提示的 15 个可延展行对。

### 1. 前沿状态为何充分

在处理完某一列后，对每对行 $`0\le u<v\le5`$，记录是否存在一个不晚于当前列的完整竖段，并且从那个竖段到当前列，第 $`u,v`$ 行的两条水平轨道都完整。

这样的行对组成状态 $`S`$，共只有

``` math

\binom62=15
```

种可能行对。

若下一步删除横边集合 $`H`$、新列竖边集合 $`V`$，定义

``` math

\begin{aligned}
C(H)&=\{(u,v):u,v\notin H\},\\
B(V)&=\{(u,v):V\cap\{u,u+1,\ldots,v-1\}=\varnothing\}.
\end{aligned}
```

旧状态经过水平边之后，只留下

``` math

S\cap C(H).
```

如果

``` math

(S\cap C(H))\cap B(V)\ne\varnothing,
```

就有一个旧的左竖边，在新列找到了完整右竖边，从而闭合出矩形。

因此一步合法的充要条件是

``` math

\boxed{(S\cap C(H))\cap B(V)=\varnothing,}
\tag{6}
```

合法时的新状态为

``` math

\boxed{S'=(S\cap C(H))\cup B(V).}
\tag{7}
```

每个正宽矩形都在其右边界所在列被检查，所以这足以排除全部矩形。

### 2. 三步之后恰好变成上下反射状态

用 $`uv`$ 简记行对 $`(u,v)`$，用 $`K(R)`$ 表示行集合 $`R`$ 中的所有二元组。令

``` math

T=K(\{0,1,2,3,4\})\cup\{35\}.
```

初始真实状态是 $`K(\{0,1,2,3,4\})`$。多出来的 $`35`$ 会在操作 $`A`$ 中被切断，因此从初始真实状态或从 $`T`$ 出发，执行 $`A`$ 后得到相同状态。

从 $`T`$ 开始，普通三步的核验如下：

<div>

<div>

<div>

| 操作  | 经过横边后存续的旧行对 $`S\cap C(H)`$ | 新列完整竖段 $`B(V)`$      |
|-------|---------------------------------------|----------------------------|
| $`A`$ | $`\{02,04,24\}`$                      | $`K(\{1,2,3\})\cup\{45\}`$ |
| $`B`$ | $`\{04,13,45\}`$                      | $`K(\{0,1,2\})\cup\{34\}`$ |
| $`C`$ | $`\{02\}`$                            | $`K(\{1,2,3,4,5\})`$       |

</div>

</div>

<div>

</div>

</div>

每行左右两集合都不相交，因此三步都满足 (6)。

第三步之后的状态为

``` math

K(\{1,2,3,4,5\})\cup\{02\}=\rho(T).
```

于是下一组反射后的三个操作又把状态带回 $`T`$。这证明了六列周期可以无限延伸。

### 3. 三步封口也合法

从执行完 $`A`$ 后的状态开始，封口三步为：

<div>

<div>

<div>

| 操作  | 经过横边后存续的旧行对 | 新列完整竖段                |
|-------|------------------------|-----------------------------|
| $`a`$ | $`\{04,13,45\}`$       | $`\{01\}\cup K(\{2,3,4\})`$ |
| $`b`$ | $`\{01,13,23\}`$       | $`\{12\}\cup K(\{3,4,5\})`$ |
| $`c`$ | $`\{45\}`$             | $`K(\{0,1,2,3,4\})`$        |

</div>

</div>

<div>

</div>

</div>

每行两集合仍然不相交，所以封口合法。上下反射当然保持这个性质。

因此构造满足

``` math

S(5,m)\le\left\lfloor\frac{10m+4}{3}\right\rfloor.
\tag{8}
```

结合 (4) 与 (8)，精确公式得证。 $`\square`$

## 四、15 位有限状态递推，以及它的长期规律

上面的上下界已经构成完整手算证明。下面再给出可独立复跑的有限状态证明，落实题目要求的递推路线。

为了简化边界条件，把状态放在“即将处理当前列竖边”的时刻。

令 $`Q`$ 表示从**严格左侧**延伸过来的开放行对，定义：

``` math

F_t(Q)=
\text{包括当前列竖边，且到右边界还剩 \(t\) 个单位宽度时的最小附加删边数}.
```

沿用上面的 $`B(V)`$、$`C(H)`$，有

``` math

\boxed{
F_0(Q)=
\min_{\substack{V\subseteq\{0,\ldots,4\}\\Q\cap B(V)=\varnothing}}
|V|.
}
\tag{9}
```

对 $`t\ge1`$，将一步分成两个阶段：

``` math

\boxed{
G_t(S)=
\min_{H\subseteq\{0,\ldots,5\}}
\left(|H|+F_{t-1}(S\cap C(H))\right),
}
\tag{10}
```
``` math

\boxed{
F_t(Q)=
\min_{\substack{V\subseteq\{0,\ldots,4\}\\Q\cap B(V)=\varnothing}}
\left(|V|+G_t(Q\cup B(V))\right).
}
\tag{11}
```

原题的答案就是

``` math

S(5,m)=F_m(\varnothing).
```

这里先检查旧 $`Q`$ 是否与本列竖段闭合，再加入本列的新竖段，因此没有把零宽矩形算进去。

### 全状态周期证书

对全部

``` math

2^{15}=32768
```

个状态，精确整数递推得到

``` math

\boxed{
F_{13}(Q)=F_{10}(Q)+10
\qquad\text{对每一个 }Q\text{ 都成立}.
}
\tag{12}
```

这是一条**完整状态向量等式**。

设递推算子为 $`\mathcal T`$，即 $`F_{t+1}=\mathcal T(F_t)`$。由 (10)—(11) 直接可知

``` math

\mathcal T(f+c)=\mathcal T(f)+c.
```

因此，(12) 给出

``` math

F_{14}
=\mathcal T(F_{13})
=\mathcal T(F_{10}+10)
=F_{11}+10.
```

继续归纳得到

``` math

\boxed{
F_{t+3}=F_t+10
\qquad(t\ge10).
}
\tag{13}
```

结合有限初值，就覆盖了所有更大的 $`m`$。这一步把有限计算提升成了无限范围的证明。
