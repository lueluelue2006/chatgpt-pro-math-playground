## 题目

设 $`4A=\{a+b+c+d:a,b,c,d\in A\}`$，加数允许重复。对每个整数 $`k\ge5`$，令 $`A`$ 遍历所有 $`k`$ 元整数集合。问 $`|4A|`$ 能否取遍 $`4k-3`$ 到 $`\binom{k+3}{4}`$ 之间的所有整数，唯独缺 $`4k-2`$、$`4k-1`$、$`4k+2`$？

## 答复结果

所给的整数区间恰好缺题目列出的三个值。
