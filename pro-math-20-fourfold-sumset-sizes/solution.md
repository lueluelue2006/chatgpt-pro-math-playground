## 1. 上下界与三个排除值

记

``` math

E_k=\{4k-2,4k-1,4k+2\},
\qquad M_k=\binom{k+3}{4}.
```

由整数和集的基本不等式

``` math

|X+Y|\ge |X|+|Y|-1
```

及四个元素的无序可重复选择数，得到

``` math

4k-3\le |4A|\le M_k.
```

三个排除值也可以用一个已知结果简短推出。平移、除去公因子后，设

``` math

\min A=0,\qquad \max A=d,\qquad \gcd(A)=1.
```

Lev 的增长不等式为

``` math

|jA|-|(j-1)A|
\ge \min\{d,j(k-2)+1\},
\qquad j\ge2.
```

原文定理 2.2 明确列出了这一结果。[arxiv.org](https://arxiv.org/html/2510.23022v3)

若 $`d=k-1`$，则 $`A=[0,k-1]`$，所以 $`|4A|=4k-3`$。若 $`d\ge k`$，则二、三、四阶的三个增量都至少为 $`k`$，因此

``` math

|4A|\ge4k.
```

这排除了 $`4k-2,4k-1`$。

对于 $`4k+2`$：若 $`d\le k`$，则 $`|4A|\le4k+1`$；若 $`d\ge k+1`$，由于 $`k\ge5`$，三个增量都至少为 $`k+1`$，因此

``` math

|4A|\ge k+3(k+1)=4k+3.
```

以下只证明其余基数全部可达。

## 2. 生成函数与两个新点的调节引理

### 2.1 共零点拼接

对含零的有限集 $`B`$，定义

``` math

H_B(z)=\sum_{j\ge0}|jB|z^j,
\qquad 0B=\{0\}.
```

可以先在有限维整数格中构造。最终取足够大的整数底数 $`P`$，把坐标

``` math

(x_0,\ldots,x_r)\longmapsto \sum_i x_iP^i.
```

若所有坐标非负且不超过 $`D`$，取 $`P>4D`$，就能保持前四阶和的全部相等与不等关系。

将含零的 $`B,C`$ 放入独立坐标子空间，只合并零点，记作 $`B\vee C`$。则

``` math

|B\vee C|=|B|+|C|-1,
\qquad
H_{B\vee C}(z)=(1-z)H_B(z)H_C(z).
\tag{1}
```

证明很直接：设 $`\ell_B(x)`$ 是表示 $`x`$ 所需的最少非零加数个数，则

``` math

\sum_xz^{\ell_B(x)}=(1-z)H_B(z),
```

而独立坐标下的最少项数相加。

特别地，拼接 $`\{0,1\}`$ 增加一个“自由点”，使生成函数乘以 $`(1-z)^{-1}`$。

下面的级数同余均模 $`z^5`$，即只比较零至四阶系数。

### 2.2 关键引理：保持前三阶，连续调节第四阶

设

``` math

B=[0,n]\cup\{t\},
\qquad n\ge1,\quad n+1\le t\le4n+1.
```

**引理。** 对每个整数 $`e\in[0,n]`$，可以给 $`B`$ 添加两个点，使零至三阶基数与添加两个自由点时相同，而第四阶基数恰好减少 $`e`$。

取

``` math

C=B\cup\{M,3M+s\},
\qquad s>0,\quad M>4\max(t,s).
```

在 $`jC`$ 中，用 $`r,q`$ 分别记录两个新点的使用次数，相应的和为

``` math

(r+3q)M+qs+(j-r-q)B.
```

不同 $`M`$ 系数的层不会相交，因为余项都小于 $`M`$。

当 $`j\le2`$ 时，没有重复层。三阶唯一重复系数是 $`3`$，对应余项 $`\{0\}`$ 与 $`s+2B`$，两者不交。四阶重复层恰好如下：

<div>

<div>

| $`M`$ 的系数 | 第一组余项 | 第二组余项 |
|--------------|------------|------------|
| $`3`$        | $`B`$      | $`s+3B`$   |
| $`4`$        | $`\{0\}`$  | $`s+2B`$   |
| $`6`$        | $`\{s\}`$  | $`2s+2B`$  |

</div>

</div>

<div>

</div>

</div>

后两行因 $`s>0`$ 不相交。因此唯一的基数亏损是

``` math

e(s)=|B\cap(s+3B)|,
```

并且

``` math

H_C(z)\equiv \frac{H_B(z)}{(1-z)^2}-e(s)z^4.
\tag{2}
```

当 $`1\le s\le n+1`$ 时，

``` math

e(s)=\max(n-s+1,0)+\mathbf1_{\{s\ge t-3n\}}.
\tag{3}
```

第一项数出 $`[0,n]`$ 内的交点；第二项判断 $`t-s\in[0,3n]`$。因为 $`t-s<t`$，表示 $`t-s`$ 时不能使用 $`B`$ 中的远点 $`t`$。

式 (3) 从至少 $`n`$ 开始，在 $`s=n+1`$ 时等于 $`1`$，每步下降 $`0`$ 或 $`1`$，所以包含全部 $`1,\ldots,n`$。另取 $`s=t+1`$，便得到 $`e(s)=0`$。

引理得证。

**这个引理提供了后面所需的连续调节区间。**

## 3. 两种进位块及精确点数预算

### 3.1 三进位、四进位混合块

给定 $`m,v\ge0`$，取 $`m+v`$ 个基数 $`r_i`$，其中 $`m`$ 个为 $`3`$，$`v`$ 个为 $`4`$，令

``` math

S=\{0,1,r_1,r_1r_2,\ldots,r_1\cdots r_{m+v}\}.
```

逐位进位得到唯一的标准表示。因此

``` math

H_S(z)
=
\frac{(1-z^3)^m(1-z^4)^v}{(1-z)^{m+v+2}}.
\tag{4}
```

将其与已有集合共零点拼接，耗费 $`1+m+v`$ 个新点，并给出因子

``` math

\frac{1-mz^3-vz^4}{(1-z)^{1+m+v}}
\pmod{z^5}.
\tag{5}
```

### 3.2 纯四阶三角数块

令

``` math

T_q=\{1,3,\ldots,3^q\},
\qquad \tau(q)=\binom q2,
```

并平移使其含零。则

``` math

H_{T_q}(z)\equiv
\frac{1-\tau(q)z^4}{(1-z)^{q+1}}.
\tag{6}
```

这里的计数值得说明。四个三幂相加后，若发生进位，标准表示恰剩两个幂，不能再进位。这个标准二幂之和恰有两种四项展开，当且仅当两个指数不同且都在 $`[1,q]`$ 中：可以任择其中一个展开成三个前一幂。

相同指数只有一种展开；指数为零的项不能展开；出现指数 $`q+1`$ 时必须展开该项。因此恰有 $`\binom q2`$ 次亏损。前三阶没有等项数碰撞。

这个块共零点拼接时耗费 $`q`$ 个新点；$`q=0`$ 时不添加点。

### 3.3 合并后的公式

令

``` math

b=|B|=n+2,\qquad c=k-b,
```

并记纯自由扩张的第四阶值为

``` math

F=[z^4]\frac{H_B(z)}{(1-z)^c}.
```

使用两点调节器、混合进位块、三角数块，余下点数用自由点补足。只要

``` math

2+(1+m+v)+q\le c,
\tag{7}
```

就可以取得

``` math

\boxed{\ |4A|=F-km-v-\tau(q)-e,\qquad 0\le e\le n.\ }
\tag{8}
```

其中 $`-mz^3`$ 乘上整个自由模型的一阶系数 $`k`$，产生 $`-km`$；其他四阶差数直接相加。

若省略混合块，只需 $`q\le c-2`$，就可以取得差数

``` math

\tau(q)+e.
\tag{9}
```

## 4. 对所有 $`k\ge37`$，填满每个跳步

现在设

``` math

k\ge37,\qquad b\ge3,\qquad c=k-b\ge2,\qquad n=b-2,
```

并令

``` math

J=\binom{c+3}{2}.
```

本节证明：

``` math

\boxed{\text{式 (8)、(9) 可以取得全部差数 }0,1,\ldots,J-1.}
\tag{10}
```

这是统一构造中需要完整核验的参数步骤。

### 4.1 当 $`2\le c\le6`$

不使用混合块，让 $`q=0,\ldots,c-2`$。

因为 $`n=k-c-2\ge c`$，区间

``` math

\tau(q)+[0,n]
```

相继重叠或相邻，覆盖

``` math

[0,n+\tau(c-2)].
```

而

``` math

n+\tau(c-2)-(J-1)=k-6c-1\ge0.
```

因此覆盖到 $`J-1`$。

### 4.2 当 $`7\le c\le10`$

上一构造至少覆盖到 $`k-1`$，因为

``` math

\tau(c-2)\ge c+1.
```

再取 $`m=1,v=0`$，让 $`q=0,\ldots,c-4`$，得到连续区间

``` math

[k,k+n+\tau(c-4)].
```

其右端满足

``` math

k+n+\tau(c-4)-(J-1)=2k-8c+6\ge0.
```

两段相接，仍覆盖全部 $`[0,J-1]`$。

### 4.3 当 $`c\ge11`$：统一判据

固定

``` math

0\le m\le\left\lfloor\frac{J-1}{k}\right\rfloor,
\qquad L=c-3-m.
```

对每个 $`0\le q\le L`$，让

``` math

0\le v\le L-q,\qquad 0\le e\le n,
```

式 (8) 给出的差数包含整个区间

``` math

km+[\tau(q),\tau(q)+n+L-q].
\tag{11}
```

相邻的 $`q`$、$`q+1`$ 区间相接的条件是

``` math

2q\le n+L+1.
```

所以，只需找到 $`Q`$ 满足

``` math

Q\le L,\qquad
2(Q-1)\le n+L+1,\qquad
\tau(Q)+L-Q\ge c+1.
\tag{12}
```

此时 (11) 的并包含

``` math

[km,km+n+c+1]=[km,(m+1)k-1].
```

对所有 $`m`$ 求并，即覆盖所需差数。

右端是凹二次函数的上取整，各段下界由端点核对得到：

### 4.5 当 $`c\ge34`$

由 $`k\ge c+3`$，

``` math

m\le\left\lceil\frac c2\right\rceil,
```

## 5. 移动一个元素，拼接整个大基数区间

取

``` math

B_t=[0,n]\cup\{t\},
\qquad n+1\le t\le4n+1.
```

直接按使用 $`t`$ 的次数分层，可以数得

``` math

|jB_t|
=
1+\sum_{i=1}^{j}\min(t,in+1).
\tag{13}
```

一种核对方式是从右到左加入区间

``` math

[(j-i)t,(j-i)t+in];
```

每一步新增的整数个数恰为 $`\min(t,in+1)`$。

定义

``` math

F_{b,c}(t)
=
[z^4]\frac{H_{B_t}(z)}{(1-z)^c},
\qquad b=n+2.
```

由 (13)，当 $`t`$ 增加 $`1`$ 时，二、三、四阶基数分别增加至多 $`1,2,3`$，一阶不变。因此

``` math

0\le F_{b,c}(t+1)-F_{b,c}(t)
\le \binom{c+1}{2}+2c+3
=J.
\tag{14}
```

第 4 节已经证明：每个区间

``` math

[F_{b,c}(t)-J+1,F_{b,c}(t)]
```

的所有整数都可达。由 (14)，这些区间相接，覆盖

``` math

[F_{b,c}(n+1),F_{b,c}(4n+1)].
```

再看两个端点：

- $`t=n+1`$：核心是一个 $`b`$ 元等差数列。
- $`t=4n+1`$：远点在前四阶上等价于给 $`[0,n]`$ 添加一个自由点。

所以这一段的右端，恰好等于下一段——核心大小变成 $`b-1`$、自由点数变成 $`c+1`$——的左端。

令 $`b`$ 从 $`k-2`$ 依次下降到 $`3`$，所有区间首尾相接。

对一个 $`b`$ 元等差数列，

``` math

H(z)=\frac{1+(b-2)z}{(1-z)^2}.
```

最初端点是 $`k-2`$ 元等差数列加两个自由点，其第四阶系数为

``` math

[z^4]\frac{1+(k-4)z}{(1-z)^4}
=35+20(k-4)=20k-45.
```

最终端点是两个等差数列点加 $`k-2`$ 个自由点，生成函数为 $`(1-z)^{-k}`$，第四阶系数为 $`M_k`$。

因此

``` math

\boxed{
[20k-45,M_k]\subseteq\mathcal R(4,k)
\qquad(k\ge37).
}
\tag{15}
```

## 6. 覆盖小基数区间

这一部分的构造实际上对 $`k\ge13`$ 就成立。

令

``` math

D=10k-74.
```

对每个

``` math

k-2\le d\le D,
```

构造一个 $`k-1`$ 元集合 $`B\subseteq[0,d]`$，使它：

1.  包含 $`[0,3]\cup[d-3,d]`$；
2.  相邻元素间距至多为 $`10`$。

在 $`3`$ 与 $`d-3`$ 之间加入网格点即可。所需点数至多为

``` math

7+\left\lceil\frac{d-6}{10}\right\rceil\le k-1.
```

然后在 $`[0,d]`$ 内补足点数。

取三个端部区间相加，其中 $`j`$ 个取高端，得到

``` math

I_j=[j(d-3),jd+3(3-j)],
\qquad j=0,1,2,3.
```

每个 $`I_j`$ 包含十个连续整数。由于 $`B`$ 的最大间距为 $`10`$，$`I_j+B`$ 是一个完整整数区间。这四个区间相继重叠，首尾分别为 $`0,4d`$，所以

``` math

4B=[0,4d].
\tag{16}
```

对 $`u=1,2,3,4`$，令

``` math

A=\{0\}\cup(u+B).
```

因为 $`[0,3]\subseteq B`$，集合 $`4A`$ 包含

``` math

[ju,j(u+3)],\qquad 1\le j\le4,
```

这些区间相接；同时四个非零加数给出

``` math

[4u,4u+4d].
```

于是

``` math

4A=\{0\}\cup[u,4u+4d],
\qquad
\boxed{|4A|=4d+3u+2.}
\tag{17}
```

四个模 $`4`$ 剩余类的首项分别为

``` math

4k-3,\quad4k,\quad4k+3,\quad4k+6.
```

这恰好留下 $`E_k`$ 中的三个值。

让 $`d`$ 增至 $`D`$，四个剩余类完整覆盖到 $`4D+8`$。而

``` math

4D+8=40k-288\ge20k-45
\qquad(k\ge13).
```

结合 (15)，**所有 $`k\ge37`$ 的定理已经得到完全解析的证明。**

## 7. 完整处理 $`5\le k\le36`$

这里使用一个便于有限验证的精确构造公式。

### 7.1 分母进位公式

设整数核心 $`B`$ 含相邻两个整数。平移后令 $`0,1\in B`$。取

``` math

q_i\in\{2,3,4,5\},\qquad Q_i=q_1\cdots q_i,
```

添加

``` math

\frac1{Q_1},\ldots,\frac1{Q_s},
```

最后统一清分母，得到整数集合 $`A`$。

则

``` math

H_A(z)
=
H_B(z)\prod_{i=1}^{s}(1+z+\cdots+z^{q_i-1}).
\tag{18}
```

证明：每 $`q_i`$ 枚第 $`i`$ 层分数可进成上一层一枚，最终进成核心中的 $`1`$，节省的项数用零补足。剩余小数部分唯一表示为

``` math

\sum_i\frac{d_i}{Q_i},
\qquad 0\le d_i<q_i,
```

并位于 $`[0,1)`$。给定数字串后，整数部分恰取遍

``` math

\left(h-\sum_i d_i\right)B.
```

不同数字串对应不同小数部分，所以得到 (18)。允许平移后的核心含负数，不影响论证。

令

``` math

b=|B|,\quad s=k-b,\quad
x=|2B|,\ y=|3B|,\ z_4=|4B|,
```

并记

``` math

P_2=x+sb+\binom{s+1}{2},
```
``` math

P_4=z_4+sy+\binom{s+1}{2}x
+\binom{s+2}{3}b+\binom{s+3}{4}.
```

若基数 $`2,3,4`$ 分别出现 $`a,u,v`$ 次，其余为 $`5`$，则

``` math

\boxed{
|4A|
=
P_4-aP_2+\binom a2-uk-v,
\quad a,u,v\ge0,\quad a+u+v\le s.
}
\tag{19}
```

这是生成函数分子

``` math

1-az^2-uz^3+\left(\binom a2-v\right)z^4
\pmod{z^5}
```

的精确展开。

### 7.2 实际穷举的有限集合族

脚本只使用以下四族：

1.  **五元素核心**：$`[0,22]`$ 内所有包含 $`0,1`$ 的五元素集合。
2.  **三进制核心**：
    ``` math

    \{(3^i-1)/2:0\le i<b\},\qquad2\le b\le8.
    ```
3.  **至多两个孔的核心**：取 $`0\le h\le2`$、$`3\le b\le36`$，令 $`n=b-2+h`$。从 $`[0,n]`$ 删除 $`h`$ 个内点，要求剩余前缀仍含相邻整数，再添加
    ``` math

    t\in[n+1,4n+1].
    ```
4.  **直接使用两个远点**：
    ``` math

    [0,k-3]\cup\{t,u\},
    ```
    其中
    ``` math

    k-2\le t\le4(k-3)+1,\qquad t+1\le u\le4t+1.
    ```

前三族应用 (19) 的全部允许参数。第四族直接计算四次和集。

核心的各阶和集由精确整数位集合计算；每一个被标记的基数都对应明确的整数集合。程序对每个 $`k=5,\ldots,36`$ 检查的是：

``` math

\text{生成的完整基数集合}
=
[4k-3,M_k]\setminus E_k.
```

因此，这一有限检查证明了所有剩余的 $`k`$。
