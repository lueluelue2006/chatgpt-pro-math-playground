## 1. 原题核对

你给出的论文把

``` math

w\langle p\rangle=w_0w_pw_{2p}\cdots
```

定义为从位置 $`0`$ 开始抽取的子序列，与本题完全一致。其第 6 节命题 28 明确排除了 $`(5,8)`$，作者猜测它是否定情形；作者发布的表 1 批量验证脚本也显式跳过了这一对。[arxiv.org+1](https://arxiv.org/html/2605.29853v1)

以下不存在性结论由本次建立的有限证书给出。证明的核心是：**将所有可能的长词压到一个 96 状态的投影图，再证明其中输出无平方词的路径至多走 48 步。**

## 2. 逐字枚举与重命名归一化

称有限词 $`u`$ **合法**，如果

``` math

u,\qquad u[::5],\qquad u[::8]
```

都无平方。

任何长度至少为 $`2`$ 的合法词，其前两个字母必须不同。将首字母重命名为 $`0`$，第二个字母重命名为 $`1`$，余下字母重命名为 $`2`$，得到唯一规范形，记为 $`\rho(u)`$。

因此，枚举时固定开头为 01，恰好保留每个字母重命名等价类的一份代表。

追加字母时，严格使用你指定的检查方式：

- 原词只检查新产生的后缀平方；
- 新位置是 $`5`$ 的倍数时，检查第 5 轨的新后缀平方；
- 新位置是 $`8`$ 的倍数时，检查第 8 轨的新后缀平方。

长度为 $`m`$ 的轨道，只需比较末尾两个长度为

``` math

k=1,\ldots,\lfloor m/2\rfloor
```

的块。所有比较都直接比较字符，不使用概率散列。

令 $`P_n`$ 为长度 $`n`$ 的合法规范形集合。完整枚举得到：

## 3. 用 201 字窗口建立有限图

取窗口移动步幅

``` math

40=\operatorname{lcm}(5,8).
```

建立有向图 $`G`$：

- 顶点为 $`P_{201}`$；
- 每个 $`e\in P_{241}`$ 给出一条边
  ``` math

  e[0:201]\longrightarrow \rho\bigl(e[40:241]\bigr).
  ```

所有区间都按 Python 的左闭右开记法书写。

### 关键对应

**任何长度为 $`201+40t`$ 的合法词，都给出 $`G`$ 中一条恰有 $`t`$ 条边的行走。**

理由如下。依次取从

``` math

0,40,80,\ldots,40t
```

开始的 201 字窗口。因为每个起点都同时被 $`5`$ 和 $`8`$ 整除，截取窗口不会改变两条抽样轨道的相位。每对相邻窗口共同位于一个合法的 241 字窗口中，其规范形正好给出上面定义的一条边。

这一步同时处理了“不同窗口可能使用不同字母重命名”的问题：边的终点再次取 $`\rho`$，恰好就是下一窗口的规范形。

## 4. 把循环部分投影到第 8 轨

对上述三个非平凡分量中的每条内部边 $`e`$，以及字母表的每个置换 $`\sigma\in S_3`$，取

``` math

z=\sigma\bigl(e[::8]\bigr).
```

因为 $`|e|=241`$，所以 $`|z|=31`$。

建立另一张图 $`H`$，加入边

``` math

z[0:26]\longrightarrow z[5:31],
```

并给这条边标上输出

``` math

z[26:31].
```

相同的 26 字词合并为同一顶点，重复边只保留一次。由此直接得到：

``` math

\boxed{|V(H)|=96,\qquad |E(H)|=102.}
```

每条边输出恰好 5 个字母。完整的 96 个状态词、102 条边及其输出标签均在证书中。

### 为什么这个合并不会遗漏真正的解？

这是整个证明中需要特别核实的一点。

首先，加入全部六种字母置换，确保每个窗口的实际字母命名都包含在图中。

其次，相邻窗口的第 8 轨确实重叠。对从位置 $`40i`$ 开始的边窗口，输出的五个字母是

``` math

w_{40i+208},\ w_{40i+216},\ w_{40i+224},\ w_{40i+232},\ w_{40i+240}.
```

下一条边的输出从

``` math

w_{40i+248}
```

继续。它们拼起来恰好是 $`w\langle8\rangle`$ 的连续因子。

因此：

> 原词在 $`G`$ 的一个非平凡分量内连续走 $`t`$ 条内部边，必定给出 $`H`$ 中一条 $`t`$ 边的路径，其输出是长度 $`5t`$ 的无平方词。

合并相同抽样状态可能增加一些并非来自原词的路径，但不会删除真正来自原词的路径。这种放宽适用于不存在性反证。

### 这个有限核还有一个可以逐字核验的结构性解释

图 $`H`$ 有四个确定的 12 边圈，以及一个有 48 个顶点、54 条边的分量。四个确定圈上的无限输出必然周期化，因而含平方。

在剩下的分量中，只有六个分支点。从一个分支点到下一个分支点，有两种走法：

- 短路 $`A`$：输出 10 个字母；
- 长路 $`B`$：输出 40 个字母。

按证书中状态的编号，其终点映射分别是

``` math

A=(1\ 18)(33\ 62)(77\ 94),
```

以及

``` math

B=(1\ 77\ 62)(18\ 33\ 94).
```

此外，逐字核验六种“先长路、后短路”的 50 字输出 $`q`$，都有

``` math

q[6:26]=q[26:46].
```

也就是说，**长路后接短路必定产生一个根长为 20 的平方。**

因此，任何无限分支路径：

- 若一直走短路，每两条短路回到同一分支点，连续四条短路就产生平方；
- 若走过一条长路，此后不能再走短路，只能一直走长路；每三条长路回到同一分支点，连续六条长路又产生平方。

这给出了有限核不能支持无限无平方输出的直接结构解释。证书中的结构验证器逐字检查了上述所有等式；具体的 48 边界限则由完整路径枚举获得。

## 6. 从有限核推出长度 $`6561`$ 不可行

把 $`G`$ 的每个强连通分量缩成一个顶点，得到凝聚有向无环图 $`Q`$。

给每个分量 $`C`$ 一个内部边数上界：

``` math

b(C)=
\begin{cases}
48,&C\text{ 是上述三个非平凡分量之一},\\
0,&C\text{ 是无自环单顶点分量}.
\end{cases}
```

一条行走离开某个强连通分量后不能返回。因此，原图行走的总边数，至多是它经过的各分量内部边数上界之和，再加上分量之间的转移边数。

按拓扑序计算

``` math

F(C)=b(C)+
\max\Bigl(\{0\}\cup
\{F(D)+1:D\to C\text{ 是 }Q\text{ 的边}\}\Bigr).
```

在全部 $`45323`$ 个分量上，精确计算得到

``` math

\boxed{\max_C F(C)=158.}
```

这一数值也用另一份强连通分量算法和反向动态规划独立复核过。达到这个宽松上界的凝聚路径经过三个非平凡分量，并有 14 条跨分量边，故

``` math

158=48+48+48+14.
```

现在假设存在一个长度 $`6561`$ 的合法词。由第 3 节的窗口对应，它将在 $`G`$ 中产生

``` math

\frac{6561-201}{40}=159
```

条边的行走。

但任何合法词产生的行走至多有 $`158`$ 条边，矛盾。

所以没有长度为 $`6561`$ 的合法词。无限合法词必然有这样的前缀，故：

``` math

\boxed{\text{不存在满足题意的无限三元串。}}\qquad\square
```
