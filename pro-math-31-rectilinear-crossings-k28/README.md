# 28 点直线画完全图的最少交叉

我随手把这道题丢给了网页版 ChatGPT Pro。这里是保存下来的答复和核验材料。

## 题目

平面取 28 个不同点，无三点共线，连全部点对。每对在内部相交的线段计一次交叉。证明最小交叉数是 7233 与 7234 中的哪一个。

## 答复结果

答复给出的最小交叉数为 7234。
