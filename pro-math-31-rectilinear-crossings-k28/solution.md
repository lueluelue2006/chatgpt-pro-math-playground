## 1. 如果交叉数是 $`7233`$，所有有关的边数下界都必须取等号

对 28 点集 $`P`$，记：

- $`e_k`$：连线较少一侧恰有 $`k`$ 个其他点的点对数，$`0\le k\le13`$；
- $`F_k=\sum_{j=0}^{k}e_j`$；
- $`X`$：内部相交的线段对数。

其中平分线计入 $`e_{13}`$，每个点对只计一次。

每个凸四点集恰产生一对相交对角线，非凸四点集不产生交叉。因此，$`X`$ 就是凸四点集的数目。

另一方面，对于一个点对，其连线两侧的点数分别为 $`k,26-k`$。对四点集双重计数得到

``` math
X=3\binom{28}{4}
-\sum_{k=0}^{13}k(26-k)e_k
=\sum_{k=0}^{12}(25-2k)F_k-2457.
\tag{1}
```

这里的双重计数很直接：一个凸四点集有两条点对连线把剩余两点分开；一个非凸四点集有三条。

已知的累积浅边下界，以及中央两层比较 $`e_{13}\le e_{12}`$，给出逐项下界

``` math
(F_0,\ldots,F_{12})\ge
b:=(3,9,18,30,45,63,84,108,135,167,205,249,314).
```

具体而言，前十二项使用

``` math
F_k\ge
3\binom{k+2}{2}+\sum_{j=9}^{k}(3j-25),
\qquad 0\le k\le11,
```

最后一项使用

``` math
F_{12}\ge
\left\lceil\frac{378+F_{11}}2\right\rceil\ge314.
```

这些是原论文用于建立 $`7233`$ 下界的边计数结果。[csun.edu](https://www.csun.edu/~sf70713/publications/newexact14.pdf)

代入式 (1)，得到

``` math
X-7233
=\sum_{k=0}^{12}(25-2k)(F_k-b_k).
\tag{2}
```

右侧每一项都是非负整数，而且系数全为正。因此，若 $`X\le7233`$，就必须有 $`X=7233`$，并且**每一个 $`F_k`$ 都取等号**。于是

\tag{3}

## 2. 关键几何归约：等号构型必有 $`10+9+9`$ 三个投影块

这里调用的外部结构定理是 Cetina、Hernández-Vélez、Leaños、Villalobos 的定理 1：

> 对 $`n`$ 为 3 的倍数的点集，若所有 $`0\le k<n/3`$ 的累积浅边数均为 $`3\binom{k+2}{2}`$，则该点集是三分解的：存在三个等大的类，沿三个方向正交投影时，分别由三个不同的类占据中间块。

该定理的结论针对原来的几何点集。本证明只在 **27 点**上调用它。[arxiv.org](https://arxiv.org/pdf/1009.4736)

### 2.1 至少有七个内部点，删掉后满足这个定理

记 $`Q_p=P\setminus\{p\}`$。对于 $`0\le j\le8`$，有删点恒等式

``` math
\sum_{p\in P}F_j(Q_p)
=26F_j(P)+(j+1)e_{j+1}(P).
\tag{5}
```

原因是：

- 原来的至多 $`j`$-边，在删去两个端点以外的任一点后仍然被计数，共贡献 26 次；
- 原来的 $`(j+1)`$-边，恰在删去其较小侧的一个点后变成 $`j`$-边，共贡献 $`j+1`$ 次。

每个 27 点集均满足

``` math
F_j(Q_p)\ge3\binom{j+2}{2},\qquad 0\le j\le8.
```

对 $`j\le7`$，将式 (4) 代入式 (5)，总和恰好等于各项下界之和。因此，**每个删点集**都在这些层取等号。

对 $`j=8`$，则有

``` math
\begin{aligned}
\sum_{p\in P}\bigl(F_8(Q_p)-135\bigr)
&=26\cdot135+9\cdot32-28\cdot135\\
&=18.
\end{aligned}
```

这是 28 个非负整数之和，所以至少十项为零。

又因 $`e_0=3`$，原点集的凸包恰为三角形。去掉可能的三个凸包顶点，至少还有**七个内部点** $`p`$，使得

``` math
F_j(Q_p)=3\binom{j+2}{2},\qquad 0\le j\le8.
```

把这些内部点组成的集合记为 $`G`$，于是 $`|G|\ge7`$。对每个 $`p\in G`$，27 点定理给出一个 $`9+9+9`$ 三分解。

### 2.2 不同删点集的三种颜色必须一致

把凸包三个顶点按逆时针记为 $`a,b,c`$。

在每个好删点集的三分解中，135 条至多 8-边全部是异色边。这个计数也可直接从投影得到：对每个九元色类，选它居最左的方向旋转半周，统计两端第 $`t`$ 门的异色交换；三类相加并除去重复计数，得到恰有 $`3t`$ 条异色 $`(t-1)`$-边，$`1\le t\le9`$。其总数是

``` math
3(1+\cdots+9)=135.
```

因此三个凸包顶点分属不同颜色。以它们给颜色命名：$`a\in A,b\in B,c\in C`$。

三块投影还意味着：从三个色类的凸包中各选一点，所得三点不可能共线，否则其中的中间点会在所有非退化投影中保持居中。三色凸包的笛卡尔积连通，所以所有三色三角形具有与 $`abc`$ 相同的定向。

现在从 $`a`$ 看其他 26 个点，按从射线 $`ab`$ 到 $`ac`$ 的极角排列。

第 $`i`$ 个点与 $`a`$ 的连线，两侧分别有 $`i-1`$ 和 $`26-i`$ 个点。因此，前九位和后九位都必须与 $`a`$ 异色。这十八个点正好用尽全部 $`B,C`$ 点。三色三角形的定向又保证所有 $`B`$ 点先于所有 $`C`$ 点，所以径向色序必为

``` math
B^9A^8C^9.
```

从 $`b,c`$ 看，分别得到

``` math
C^9B^8A^9,\qquad A^9C^8B^9.
```

取两个好删点 $`p,q`$。如果它们的共有点 $`x`$ 在两份三分解中从颜色 $`A`$ 变成 $`B`$，就从第三个锚点 $`c`$ 看：$`x`$ 必须从前九位变到后九位。

但两个径向表都是从同一张 27 项表各删去一项得到的，共有点的名次最多相差一位。这不可能。

所以所有好删点集的赋色在交集上一致。它们拼成原点集 $`P`$ 的统一赋色，类大小必为

``` math
10,\ 9,\ 9.
```

### 2.3 三块投影也能从删点集恢复到原点集

还需证明：统一赋色后的 28 个点确实具有所需的严格块投影。

任意指定颜色顺序 $`U,V,W`$，定义差向量集

``` math
D=
\{y-x:x\in U,\ y\in V\}
\cup
\{z-y:y\in V,\ z\in W\}.
```

存在这个块序的严格投影，等价于存在向量 $`u`$，使

``` math
u\cdot d>0\qquad(d\in D).
```

若不存在，由严格分离定理，

``` math
0\in\operatorname{conv}D.
```

平面 Carathéodory 定理说明，只需至多三个差向量，其凸包就已经包含原点。这些差向量涉及至多六个端点。

因为 $`|G|\ge7`$，可选一个好删点 $`p`$，避开全部六个端点。这个投影障碍于是完整保留在 $`Q_p`$ 中，和 $`Q_p`$ 的三分解矛盾。

因此，原来的 28 点集也具有全部所需的严格块序。把十点类命名为 $`A`$，可选择旋转方向，使半周中依次出现

``` math
ABC\longrightarrow BAC\longrightarrow BCA\longrightarrow CBA.
\tag{6}
```

于是这个半周中的异色交换分为三个先后阶段：全部 $`AB`$ 交换、全部 $`AC`$ 交换、全部 $`BC`$ 交换。

若有平行点对连线，先做保持所有三点定向的任意小的一般位置扰动即可；交叉数及上述所有边数都不变。

## 3. 将问题化为单色交换的整数权重

旋转投影时，在位置 $`g,g+1`$ 之间发生的交换称为第 $`g`$ 门交换，$`1\le g\le27`$。设其次数为 $`m_g`$。

对应点对连线两侧有 $`g-1`$ 和 $`27-g`$ 个点。因此式 (1)可写成

``` math
X=-2457+\sum_{g=1}^{27}(g-14)^2m_g.
\tag{7}
```

也就是说，每次交换赋予权重

``` math
w(g)=(g-14)^2.
```

两个大小为 $`p,q`$ 的块从 $`UV`$ 换成 $`VU`$，若它们左侧还有 $`d`$ 个第三色点，那么第 $`g`$ 门的异色交换数为

``` math
f_{p,q}(g-d)
=\max\{0,\min(g-d,p,q,p+q-g+d)\}.
```

这是前缀中 $`V`$ 点数的净增长。

式 (6) 的三个阶段对应

``` math
(p,q,d)=(10,9,0),\ (10,9,9),\ (9,9,0).
```

合并对称门，得到异色边数

``` math
e_j^{\rm bi}=
\begin{cases}
3(j+1),&0\le j\le8,\\
28,&9\le j\le12,\\
14,&j=13.
\end{cases}
```

它们共 261 条，总权重为

``` math
\sum_{j=0}^{13}(13-j)^2e_j^{\rm bi}=9435.
```

由于异色边已经用尽全部 135 条至多 8-边，所有单色交换只能发生在门

``` math
10,11,\ldots,18.
```

记全部单色交换的权重和为 $`M`$，则

``` math
X=-2457+9435+M=6978+M.
\tag{8}
```

所以 $`X=7233`$ 要求

``` math
M=255.
```

剩下的任务是证明 $`M\ge256`$。

## 4. 所有实际单色交换都包含在一个明确的有限图中

对大小为 $`v\in\{9,10\}`$ 的一个色类，选择它占最左整块的时刻开始旋转半周，按起始内部次序把点标为 $`1,\ldots,v`$。

半周结束时，内部排列完全反转。

沿着任意一个本色点，其左侧的外色点数 $`h`$ 单调不减：每个外色点都只从它右侧越到左侧一次。

一次本色交换若发生在内部第 $`r,r+1`$ 位，且两点左侧有 $`h`$ 个外色点，那么实际门是

``` math
g=r+h,
```

权重为

``` math
(r+h-14)^2.
```

关键是：**可以把单色交换按 $`h`$ 稳定排序，保持每次交换的内部门 $`r`$ 和权重。**

因为两次 $`h`$ 倒序的交换不能共享一个点，否则该点的外色左邻数会下降。相邻的两个不共享标签的换位作用在不交的位置对上，可以交换先后而不改变各自的门。逐次消除倒序即得结论。

因此定义如下有限有向图：

``` math
(h,\pi),\qquad
0\le h\le28-v,\quad \pi\in S_v.
```

允许两种弧：

1.  $`(h,\pi)\to(h+1,\pi)`$，权重为零。
2.  若 $`\pi_r<\pi_{r+1}`$ 且 $`10\le h+r\le18`$，交换这两个相邻标签，权重为 $`(h+r-14)^2`$。

起点为

``` math
(0,(1,\ldots,v)),
```

终点为

``` math
(28-v,(v,\ldots,1)).
```

每次交换增加一个逆序，因此图无环。每条真实单色交换轨迹都给出这个图中的同权路径。

不同色类选用不同的起始半周，不改变所计权重：反向投影把门 $`g`$ 变为 $`28-g`$，而两者的平方权重相同。

对这个有限图作整数最短路计算，得到无额外限制时

``` math
m_9=74,\qquad m_{10}=106.
\tag{9}
```

单独相加只有 $`254`$，所以还需要不同色类之间的相容性约束。

## 5. 双色互斥条件与完整有限证书

### 5.1 一个可以直接证明的互斥条件

令三个颜色为 $`x=0,1,2`$，大小依次为

``` math
(v_0,v_1,v_2)=(10,9,9),
```

色标按模 3 计算。对每个 $`x`$，令 $`y=x+1`$。

在 $`x`$ 首先与 $`y`$ 交换整块的阶段，第三色整体在右边。暂时略去第三色，块序从 $`xy`$ 变成 $`yx`$。

任取

``` math
1\le r<v_x,\qquad1\le s<v_y,
```

考察两类单色交换：

- 两个 $`x`$ 点在本色内部门 $`r`$ 交换，左边有 $`s`$ 个 $`y`$ 点；
- 两个 $`y`$ 点在本色内部门 $`s`$ 交换，左边有 $`r`$ 个 $`x`$ 点。

它们都位于块内的第 $`k=r+s`$ 门。

第一种交换发生时，长度为 $`k-1,k+1`$ 的两个前缀中的 $`y`$ 点数为

``` math
(s,s).
```

第二种交换发生时，对应计数为

``` math
(s-1,s+1).
```

但在 $`xy\to yx`$ 的整个阶段中，每个固定前缀内的 $`y`$ 点数都单调不减。这两个向量逐坐标不可比，所以两种交换**不能都发生**。

在 $`x`$ 自己的图中，第一种交换的标记是 $`(r,s)`$。把第二种交换改写到 $`y`$ 自己采用的半周，其投影顺序整体反向，标记变成

``` math
(v_y-s,\ 28-v_y-r).
```

因此每个实际构型都满足以下析取：

``` math
\boxed{
\text{色 }x\text{ 禁用 }(r,s)
\quad\text{或}\quad
\text{色 }y\text{ 禁用 }(v_y-s,\,28-v_y-r).
}
\tag{10}
```

这里“禁用 $`(r,h)`$”是指禁止该阶段内这个内部门的全部交换。

这个整格禁用是有效的：$`0<s<v_y`$ 将第一种标记严格定位到 $`x`$ 的第一阶段；反射后的外色点数严格落在 $`y`$ 的第二阶段，该阶段恰是前者的反向投影。因此不会把另一阶段的合法交换误禁掉。

``` math
\overline{\operatorname{cr}}(K_{28})\le7234.
```

与式 (11) 合并，得到所求等式。
