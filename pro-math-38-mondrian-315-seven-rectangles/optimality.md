# 150 是最小面积差

这部分整理后续网页版 ChatGPT Pro 答复的下界论证。首轮答复的七块坐标已给出面积差 150 的构造。

## 有限搜索

用整数单位格表示分割不会丢解。穿过某块矩形内部并避开水平边的水平截线，把正方形截成若干整数长度的区间。从左边界累加就得到该矩形的两条竖边坐标。竖直截线同样确定两条横边的整数坐标。

若允许的面积差为 $`D`$，一块面积为 $`A`$ 时，其余六块的面积都落在 $`[A-D,A+D]`$。因为总面积为 $`315^2=7\cdot14175`$，每块面积都在 $`14175\pm\lfloor6D/7\rfloor`$ 之间。取 $`D=149`$ 时，允许范围是 14048 至 14302。

## 搜索完备性

从空正方形开始，记录每列自底部连续填满的高度。选全体空单位格中最低且最靠左的一格，设其左下角为 $`(x,y)`$。任何兼容的铺法中，覆盖该格的矩形左下角必是 $`(x,y)`$。向下延伸会与该列的已填部分重叠。向左延伸会覆盖一个同样低却更靠左的空格，或与已填部分重叠，均不可能。

枚举在该位置能放入的所有整数宽高。矩形只能横跨从 $`x`$ 开始与 $`y`$ 同高的相邻列。放置之后每列仍从底部连续填满。对任何合法目标拼法反复应用这一性质，就得到一条完整的枚举路径。

两份程序都要求剩余面积与剩余矩形数相容，并按排序后的边长对排除全等块。主程序还用当前不同的未填列高度数作为剩余块数下界。每个这样的高度都必须是某块尚未放入的矩形的下边高度。主程序用沿对角线反射的对称性，只枚举首块宽不超过高的布局。

独立程序保留两个方向，使用分区面积和必需的矩形下边位置作额外剪枝。满列会把剩余格子隔成几个竖条区间，每个区间需要由整块矩形铺满。对于每个未填列顶部，覆盖其上方单位格的矩形必须以该高度作下边，且只能横跨列高不超过该高度的连续区间。在同一高度上被更高列隔开的区间需要分别放一块矩形。

## 如何复跑

```sh
c++ -O3 -std=c++17 verify_315.cpp -o verify_315
./verify_315 149
./verify_315 150

c++ -O3 -std=c++17 independent_verify.cpp -o independent_verify
./independent_verify
```

| 最大允许面积差 | GPT Pro 验证器 | 独立验证器 |
| ---: | ---: | ---: |
| 149 | 0 | 0 |
| 150 | 64 | 128 |

GPT Pro 验证器的 64 计入了首块方向约定。独立程序的 128 保留了两个方向。由于所有面积差都是整数，149 无解与 150 有解共同证明精确最小值为 **150**。
