## 2. 为什么恰好铺满，没有重叠或空隙

这组坐标可以通过以下**六次直线切割**得到。每次都只切开一个已有矩形，因此覆盖关系可以直接核查：

1.  沿 $`x=90`$ 把整个正方形分成左侧 $`90\times315`$ 和右侧 $`225\times315`$ 两块。
2.  把左侧矩形沿 $`y=157`$ 切开，得到 $`R_1,R_2`$，高度分别为 $`157,158`$。
3.  把右侧矩形沿 $`y=126`$ 切开，得到下方 $`225\times126`$ 和上方 $`225\times189`$ 两块。
4.  把右侧下方矩形沿 $`x=202`$ 切开，得到 $`R_3,R_4`$，宽度分别为 $`112,113`$。
5.  把右侧上方矩形沿 $`x=165`$ 切开，得到 $`R_5`$ 和一个 $`150\times189`$ 矩形。
6.  把最后这个矩形沿 $`y=220`$ 切开，得到 $`R_6,R_7`$，高度分别为 $`94,95`$。

所用的分割等式是

``` math
\begin{aligned}
315&=90+225,\\
315&=157+158=126+189,\\
225&=112+113=75+150,\\
189&=94+95.
\end{aligned}
```

因此，七块矩形的并集恰为整个正方形，内部两两不相交；公共边界是正常的切割边界。所有边长也显然都是正整数。

## 3. 为什么互不全等，且面积差只有 150

七块的平均面积为

``` math
\mu=\frac{315^2}{7}=\frac{99225}{7}=14175.
```

这组构造的七个面积恰好组成集合

``` math
\left\{
\mu-75,\;
\mu-63,\;
\mu-45,\;
\mu,\;
\mu+45,\;
\mu+63,\;
\mu+75
\right\}.
```

也就是

``` math
14100<14112<14130<14175<14220<14238<14250.
```

**七个面积全部不同。** 全等矩形必有相同面积，旋转也不改变面积，因此任意两块即使旋转也不可能全等。

最大面积属于 $`R_7`$，最小面积属于 $`R_6`$，所以

``` math
\operatorname{def}
=(\mu+75)-(\mu-75)
=\boxed{150}.
```

至此，题目要求的全部条件已经验证完毕。

### 与已知 280 构造的关系

O’Kuhn–Slaughter 论文中的“280 最优”只针对其特定参数族；原文明确说明，这并不是所有七矩形拼法的下界。因此，上面的构造与该论文的已证结论一致。[arxiv.t3mt.com](https://arxiv.org/html/2610.19193v1)

若记 $`M_7(315)`$ 为本题恰好七块时的最小面积差，我们已经严格证明

``` math
\boxed{M_7(315)\le150<280.}
```

这解决了你提出的“能否小于 280”的判定问题；这里没有声称 $`150`$ 就是最优值。
