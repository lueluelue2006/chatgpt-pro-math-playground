# 十三个整数的等差交集

我随手把这道题丢给了网页版 ChatGPT Pro。这里是保存下来的答复和核验材料。

## 题目

从 {1,…,13} 中选尽可能多的不同非空子集。要求任意两个所选子集的交集是非空等差数列，单元素集和二元素集均算等差数列。最多能选多少个？

## 答复结果

最大集合数为 82。
