### 为什么所有交集都合格？

所有成员都包含 $`7`$，所以交集非空。

- 若有一个成员大小至多为 $`2`$，交集大小也至多为 $`2`$，合格。
- 两个不同的三元组，交集大小至多为 $`2`$，合格。
- 两个新增成员都是等差数列，它们的非空交集仍是等差数列。
- 剩下只需检查一个保留的三元组 $`T`$ 与一个新增成员 $`P`$。若交集至多两点，合格；若交集有三点，则 $`T\subseteq P`$。

对于最后一种情况，$`P`$ 包含在某个五项等差窗口

``` math
\{7-2d,\,7-d,\,7,\,7+d,\,7+2d\},
\qquad d\in\{1,2,3\}
```

中。窗口内包含 $`7`$ 的三元组共有六个，其中恰好两个不等差：

``` math
\{7-2d,7,7+d\},\qquad
\{7-d,7,7+2d\}.
```

它们正是已经删除的三元组。因此剩下的交集全部合格。

这证明了

``` math
M\ge82.
```

附件还直接检查了这个构造的全部

``` math
\binom{82}{2}=3321
```

对交集。

## 二、上界的组织方式

建立一个有限图 $`G`$：

- 顶点是 $`[13]`$ 的全部 $`8191`$ 个非空子集；
- 两个不同顶点 $`A,B`$ 相邻，当且仅当 $`A\cap B`$ 是非空等差数列。

题目等价于求这个图的最大团。**单个成员自身可以不是等差数列；这些顶点全部保留在搜索空间中。**

为了证明上界，只需排除一个 $`83`$ 顶点的团。证明分为：

1.  核验有公共元素的集合族至多有 $`82`$ 个成员；
2.  穷尽排除含二元素成员的 $`83`$ 元族；
3.  用一个线性代数引理，把剩余情况归约到有限的“大交集”分支，再穷尽排除。

下面说明每一步的依据，以及穷尽搜索为何覆盖全部可能性。

合法集合族构成团，而一个团在同一种颜色中至多取一个顶点，所以该表证明了公共元素情形的上界。

这个着色有明确、可检查的构造。

先给包含 $`c`$、大小至多为 $`3`$ 的集合各一个颜色，共 $`79`$ 色。对较大的非等差集合 $`A`$，找一个含 $`c`$ 的三元组 $`T\subseteq A`$，使得

``` math
\operatorname{hull}(T)\not\subseteq A,
```

其中 $`\operatorname{hull}(T)`$ 是包含 $`T`$ 的最小等差数列，然后使用 $`T`$ 的颜色。较大的等差集合则通过一个小型二分匹配，分配到它们所包含的非等差三元组颜色；未匹配者各用一个新颜色。

程序对每个 $`c`$ 都完成全部 $`4096`$ 个集合的赋色，然后**直接逐对检查每个颜色类中的不同集合确实不相邻**。因此，这一步可以完全通过有限检查复核，无须引用一个未经验证的一般结构定理。

特别地，如果集合族含有单元素集 $`\{c\}`$，那么它的所有成员都含 $`c`$，故大小至多为 $`82`$。

## 四、关键引理：小交集情形实际上至多 79

这是缩小穷尽搜索范围的主要数学步骤。

> **引理。** 设 $`\mathcal F`$ 是本题的合法集合族，所有成员大小至少为 $`3`$。如果任意两个不同成员的交集都至多有 $`5`$ 个元素，那么
>
> ``` math
> |\mathcal F|\le79.
> ```

### 1. 定义一个带符号的双线性型

坐标以空集，以及全部一项、二项、三项、四项等差数列 $`T`$ 为指标。坐标总数是

``` math
1+13+78+36+22=150.
```

对任意集合 $`A`$，定义向量

``` math
\Phi(A)_T=\mathbf1_{\{T\subseteq A\}}.
```

给空集坐标和二元集坐标正号，其余坐标负号。于是正坐标有

``` math
1+\binom{13}{2}=79
```

个，负坐标有 $`71`$ 个。

相应的双线性型满足

``` math
\langle\Phi(A),\Phi(B)\rangle=f(A\cap B),
```

其中

``` math
f(X)=1-|X|+\binom{|X|}{2}-a_3(X)-a_4(X),
```

$`a_3(X),a_4(X)`$ 分别表示 $`X`$ 中三项、四项等差子集的个数。

### 2. 一个很短的有限检查

对 $`[13]`$ 的全部非空子集，整数运算核验得到

``` math
f(X)\ge0,
```

并且

``` math
f(X)=0
\quad\Longleftrightarrow\quad
X\text{ 是长度 }1,2,3,4,5\text{ 的等差数列}.
\tag{1}
```

按集合大小 $`1,\ldots,13`$ 分组，$`f`$ 的最小值依次为

``` math
0,0,0,0,0,1,1,2,3,4,5,7,8.
```

这一步只有 $`8191`$ 个输入。下面这段独立代码就能完整检查式（1）：

### 3. 所需的零值向量线性独立

在引理条件下，不同成员的交集是长度至多为 $`5`$ 的非空等差数列，所以

``` math
\langle\Phi(A),\Phi(B)\rangle=0
\qquad(A\ne B).
```

自身二次型值为零的成员，只能是长度 $`3,4,5`$ 的等差数列，共

``` math
36+22+15=73
```

种。这 $`73`$ 个向量线性独立。下面给出直接证明。

首先，大小至多为 $`4`$ 的全部等差数列，包括空集，其包含关系矩阵按大小排列后是单位三角矩阵，因而对应向量线性独立。

对五项等差数列 $`P=\{a,b,c,d,e\}`$，逐坐标验证有

``` math
\begin{aligned}
\Phi(P)
={}&\Phi(\{a,b,c,d\})+\Phi(\{b,c,d,e\})\\
&-\Phi(\{b,c,d\})+\Phi(\{a,c,e\})\\
&-\Phi(\{a,c\})-\Phi(\{c,e\})+\Phi(\{c\}).
\end{aligned}
\tag{2}
```

假设长度 $`3,4,5`$ 的这些向量存在一个非零线性关系，用式（2）展开所有五项向量。

固定一个出现非零五项系数的公差 $`h`$，并取该公差下非零系数窗口的最小中心 $`c`$。在展开后的独立小集合向量中，二元集

``` math
\{c-2h,c\}
```

的系数非零：除了中心为 $`c`$ 的窗口，唯一可能贡献的窗口中心是 $`c-2h`$，其系数依最小性为零。矛盾。

所以五项系数全为零，其余系数再由三角性全为零。独立性得证。附件另用模 $`2`$ 消元核验了这 $`73`$ 行的秩确为 $`73`$。

### 4. 得出 79 上界

若所选向量有线性关系，分别与每个自身二次型值为正的选中向量取内积，可知这些向量的系数全部为零。剩下的零值向量又线性独立，所以全部选中向量线性独立。

另一方面，它们两两正交，自身二次型非负，故张成一个二次型非负的子空间。

这个子空间到 $`79`$ 个正坐标的投影是单射：若一个非零向量的正坐标全为零，它的二次型便严格为负，矛盾。

因此

``` math
|\mathcal F|\le79.
```

引理证毕。

### 第二段搜索：以两对大交集成员作根

把交集至少有六项的兼容成员对称为“大交集边”。

根据上面的引理，$`83`$ 元族必有大交集边。更关键的是：

**删去任意一条大交集边的两个端点后，剩下 $`81`$ 个成员，仍然必有大交集边。**

因为如果没有，剩下的族就满足引理，大小应至多为 $`79`$。

全空间中，大交集边恰有

``` math
15927
```

条。这个数字也能单独核对：固定一个 $`k`$ 项交集 $`P`$，在 $`P`$ 外的每个元素有“不进入任何一方、只进入第一方、只进入第二方”三种选择，所以无序且不同的成员对有

``` math
\frac{3^{13-k}-1}{2}
```

个。对所有长度至少为 $`6`$ 的等差数列 $`P`$ 求和，即得 $`15927`$。

搜索按下面的顺序完整分解：

1.  按族中的**第一条大交集边** $`e`$ 分组；
2.  在除去 $`e`$ 两个端点后的 $`81`$ 个成员中，按**第一条大交集边** $`f`$ 再分组；
3.  四个端点确定后，在它们的公共邻域中搜索剩余 $`79`$ 个成员。

每次把已经处理过的较早边删除，恰好实现这个“第一条边”的分组。因此，每个潜在的 $`83`$ 元族都会进入相应分支。

### 搜索内部为什么不会漏解？

程序使用的是精确的分支搜索。剪枝依据只有：

- 剩余顶点数不足；
- 团中顶点所需的内部度数不足；
- 合法贪心着色给出的团大小上界不足；
- 某个完成方案必有公共元素，使用已经核验的公共元素上界；
- 第二段中某个完成方案必被一个二元集击中，使用第一段搜索的结论。

着色分支的完备性也很直接：若还需要 $`r`$ 个顶点，前 $`r-1`$ 个颜色类最多贡献 $`r-1`$ 个团顶点，因此任何完成方案必含第 $`r`$ 色及以后颜色中的某个顶点。程序逐个选择这些顶点继续搜索，覆盖全部可能性。
