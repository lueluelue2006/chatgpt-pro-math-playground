# 十三边形的最少五边形内面

我随手把这道题丢给了网页版 ChatGPT Pro。这里是保存下来的答复和核验材料。

## 题目

在有限简单平面图中，外面的边界为 13 边形，每个内部面的边界为五边形。要求删除任意至多两个顶点后图仍连通。内部面数的最小值是 27 还是 29？

## 答复结果

最少内部五边形面为 27。
