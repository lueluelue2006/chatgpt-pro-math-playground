## 三、围长恰为 5

从 $`H`$ 的边表可直接检查：



## 五、精确解存在：有理数收缩证书

把自由坐标合成向量 $`t\in\mathbb R^{78}`$，中心向量记为 $`c`$。令

``` math
X=\{t:\|t-c\|_\infty\le1\}.
```

按边的字典序排列上述方程，记其左端减去 $`S^2`$ 所得向量为 $`F(t)`$。令

``` math
J=DF(c).
```

这里 $`J`$ 是完全由上表确定的 $`78\times78`$ **整数矩阵**。

验证程序通过整数消元求出整数矩阵 $`A`$ 和正整数 $`d`$，并逐项验证

``` math
AJ=dI.
```

因而 $`J`$ 可逆，且

``` math
B=J^{-1}=\frac Ad
```

是精确有理矩阵。

对这些有理数作精确比较，得到

``` math
\eta:=\|BF(c)\|_\infty<\frac12,
\qquad
q:=16\|B\|_\infty<\frac5{12}.
```

实际计算后向外舍入的上界为

``` math
\eta\le0.49538357,\qquad
q\le0.41216906,\qquad
\eta+q\le0.90755263.
```

这里的 $`\eta`$ 使用上表的整数网格单位。

每个平方距离方程的雅可比行至多有四个非零条目。盒内每个坐标最多偏移 $`1`$，所以每个条目的变化绝对值至多为 $`4`$，从而

``` math
\|DF(t)-J\|_\infty\le16
\qquad(t\in X).
```

定义

``` math
T(t)=t-BF(t).
```

由于 $`BJ=I`$，在整个盒中有

``` math
\|DT(t)\|_\infty
=\|B(J-DF(t))\|_\infty
\le q<1.
```

同时

``` math
\begin{aligned}
\|T(t)-c\|_\infty
&\le\|T(c)-c\|_\infty+\|T(t)-T(c)\|_\infty\\
&\le\eta+q\|t-c\|_\infty\\
&\le\eta+q<\frac{11}{12}<1.
\end{aligned}
```

因此，$`T`$ 把闭盒 $`X`$ 映入自身，并在其中严格收缩。由 Banach 不动点定理，$`T`$ 在 $`X`$ 中有唯一不动点。

由于 $`B`$ 可逆，

``` math
T(t)=t\iff F(t)=0.
```

所以前一节的方程组在指定盒内**确实存在唯一实解**。这一步把构造从数值候选提升为精确的存在性证明。

## 六、检查所有点对，排除重合与额外单位距离

取任意 $`i\ne j`$，记

``` math
a=|C_{ix}-C_{jx}|,\qquad b=|C_{iy}-C_{jy}|.
```

每个坐标差的误差至多为 $`2`$，所以盒中任意一组点都满足

``` math
L_{ij}\le\|z_i-z_j\|^2\le U_{ij},
```

其中

``` math
L_{ij}=\max(0,a-2)^2+\max(0,b-2)^2,
```
``` math
U_{ij}=(a+2)^2+(b+2)^2.
```

这些全部是整数。

### 点两两不同

对全部

``` math
\binom{41}{2}=820
```

个点对，精确检查得到

``` math
\min_{i<j}\frac{L_{ij}}{S^2}
=
\frac{200093}{10^{10}}
>
\frac1{50000}>0.
```

因此实际的 41 个点两两不同。

### 非边绝不是单位距离

对每个非边 $`\{i,j\}\notin E(G)`$，区间

``` math
[L_{ij},U_{ij}]
```

均不包含 $`S^2`$。更具体地，

``` math
\left|\|p_i-p_j\|^2-1\right|
\ge
\frac{518883}{2\cdot10^9}
>
\frac1{4000}.
```

所以没有任何额外的单位距离点对。

边 $`\{0,7\}`$ 由固定坐标保证长度为 $`1`$，其余 78 条边由方程 $`F(t)=0`$ 保证长度为 $`1`$。因此

``` math
\boxed{\|p_i-p_j\|=1\iff \{i,j\}\in E(G).}
```

这证明实现的是题目所要求的全部单位距离图。
