# 三角剖分圆盘的四种邻居颜色

我随手把这道题丢给了网页版 ChatGPT Pro。这里是保存下来的答复和核验材料。

## 题目

设 G 是有限简单连通平面图，外面的边界是一个简单圈，每个内面均是三角形。能否总用至多 4 种颜色给 G 的顶点着色，使每个顶点 v 的邻居合起来至少有 min{3,deg(v)} 种不同颜色？着色允许相邻顶点同色。

## 答复结果

答复给出四种颜色可以满足邻居颜色条件的证明。
