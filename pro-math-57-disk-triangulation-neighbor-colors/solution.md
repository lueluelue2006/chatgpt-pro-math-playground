下面给出完整证明。唯一直接调用的外部定理是四色定理。证明中的“匹配后同时翻边”思路来自 Kwon、Park、Sano 对完整平面三角剖分的处理；这里先证明一个保留边界的相对版本，再处理任意简单外圈。其原文的定理 1.5 陈述的是外面也为三角形的情形。[arxiv.org](https://arxiv.org/html/2611.00572v1)

全文把颜色集固定为

``` math
\Omega=\{0,1,2,3\}.
```

称着色 $`c`$ **合格**，如果每个顶点 $`v`$ 都满足

``` math
|c(N(v))|\ge \min\{3,d(v)\}.
```

“正常着色”则专指相邻顶点异色的着色；最后得到的合格着色不必正常。

## 一、处理内部顶点、保留边界的引理

这里暂时允许外面的边界经过重复顶点，因此也允许割点。

**引理。** 设 $`K`$ 是有限简单连通平面图，每个有界面都是三角形。记 $`B`$ 为在外面边界上出现的顶点集，$`I=V(K)\setminus B`$。可以在相同顶点集上构造一个无环的平面多重图 $`P`$，具有以下性质：

1.  $`K`$ 中两端都在 $`B`$ 内的边全部保留在 $`P`$ 中。
2.  在 $`P`$ 的任何正常着色下，每个 $`u\in I`$ 的 **$`K`$-邻点**至少有三种颜色。
3.  假设 $`a\in B`$ 有互异的邻点
    ``` math
    z_1,z_2,\ldots,z_k,\qquad k\ge2,
    ```
    其中 $`z_1,z_k\in B`$，且
    ``` math
    az_jz_{j+1}\quad(1\le j<k)
    ```
    都是 $`K`$ 的有界三角面。那么这些邻点至少有两种颜色。

### 证明

先在诱导子图 $`K[I]`$ 中选一个最大匹配 $`M`$，令

``` math
U=I\setminus V(M).
```

与内部顶点相接的每条边 $`ux`$ 都有两个相邻三角面。用 $`\Theta(ux)`$ 表示这两个三角面的第三顶点组成的集合；它有两个不同的元素。

称 $`u\in U`$ **被阻塞**，如果对每个邻点 $`x`$，都有某个 $`y\in\Theta(ux)`$ 使

``` math
xy\in M.
```

在所有最大匹配中，选取被阻塞顶点数最少的一个。

**先证明没有被阻塞顶点。**

假设 $`u`$ 被阻塞。它的邻点按循环顺序记为

``` math
x_1,x_2,\ldots,x_d.
```

因为每个 $`x_i`$ 都必须与循环中相邻的一个顶点匹配，$`d`$ 必为偶数且至少为 $`4`$。适当编号后，

``` math
x_1x_2,\ x_3x_4,\ \ldots,\ x_{d-1}x_d\in M.
```

这些顶点全部属于 $`I`$。

设边 $`x_2x_3`$ 的两个相邻三角面的第三顶点为 $`u,w`$。可以选择编号方向，使 $`w\ne x_4`$：反向编号会互换 $`x_1,x_4`$ 的角色，而它们不同。

令

``` math
M'=(M\setminus\{x_1x_2\})\cup\{ux_1\}.
```

这是同样大小的最大匹配；未匹配顶点中，$`u`$ 被 $`x_2`$ 替代。由于 $`x_3`$ 仍与 $`x_4`$ 匹配，且

``` math
x_4\notin\Theta(x_2x_3)=\{u,w\},
```

新未匹配顶点 $`x_2`$ 没有被阻塞。

对于其他原来未匹配的顶点 $`u'`$，它不邻接 $`u,x_1,x_2`$。否则，原匹配中存在长度 $`1`$ 或 $`3`$ 的增广路，例如

``` math
u'-x_1-x_2-u.
```

因此，$`u'`$ 的所有邻点的匹配情况均未改变，其是否被阻塞也未改变。于是 $`M'`$ 的被阻塞顶点更少，矛盾。

所以，每个 $`u\in U`$ 都可以选一个邻点 $`x(u)`$，使边 $`ux(u)`$ 的两个相邻三角面均不含 $`M`$ 中的边。令

``` math
F=M\cup\{ux(u):u\in U\}.
```

这个边集具有三个性质：

- 每个内部顶点都与 $`F`$ 中的边相接；
- 每个有界三角面至多含一条 $`F`$-边；
- 每个 $`u\in U`$ 在子图 $`(V(K),F)`$ 中的度恰好为 $`1`$。

第二、第三点的原因是：$`U`$ 是独立集。如果两个不同未匹配顶点所选的边位于同一三角面，这两个顶点就相邻，矛盾。

现在对每条 $`e=uv\in F`$，设其相邻三角面为 $`uvs,uvt`$。删除 $`uv`$，加入另一条对角线 $`st`$。对所有 $`F`$-边同时这样做，得到 $`P`$。

由于每个三角面至多参与一次操作，各操作区域内部互不重叠，故 $`P`$ 平面；又因 $`s\ne t`$，没有环。可能出现平行边，这不影响正常着色。

若内部顶点 $`u`$ 与选中的边 $`uv`$ 相接，则它的三个原邻点 $`v,s,t`$ 在 $`P`$ 中形成三角形：

``` math
vs,\ vt,\ st\in E(P).
```

所以任何正常着色都使 $`u`$ 看到三种颜色，证明了性质 2。

每条 $`F`$-边至少有一个内部端点，所以两端都在 $`B`$ 中的边不会被删除，证明了性质 1。

最后证明性质 3。

- 若 $`k=2`$，边 $`z_1z_2`$ 两端都在 $`B`$，所以保留。
- 若 $`k\ge3`$ 且 $`z_1z_2\notin F`$，它也保留。
- 若 $`k\ge3`$ 且 $`z_1z_2\in F`$，由于 $`z_1\in B`$，这只能是未匹配内部顶点 $`z_2`$ 选取的边。$`z_2`$ 在 $`F`$ 中度为 $`1`$，所以 $`z_2z_3\notin F`$，该边保留。

每种情形下，所列邻点中都有一对在 $`P`$ 中相邻，因而异色。引理得证。 $`\square`$

## 二、两个基本补色事实

### 1. 二选一补色

假设一个顶点原本合格，现在只改动它的一个邻点的颜色。若其余邻点中已经出现颜色 $`X`$，而给被改动邻点的两个候选色互不相同、且均不等于 $`X`$，那么至少有一个候选色能保持该顶点合格。

理由很直接：若其余邻点已经有足够多颜色，任选即可。否则，原本合格说明这些邻点只差一种颜色；它们已有的颜色至多两种，并包含 $`X`$，所以至多排除两个候选色中的一个。

### 2. 删除一条边界边

设 $`uv`$ 是圆盘的一条边界边，且

``` math
d(u),d(v)\ge3.
```

设其相邻有界三角面为 $`uvx`$。

删除 $`uv`$ 后，只有两种情形：

- \*\*$`x`$ 是内部顶点：\*\*得到一个边数更少的三角剖分圆盘，新外圈把 $`uv`$ 替换为 $`u-x-v`$。
- \*\*$`x`$ 已在外圈上：\*\*得到两个边数更少的三角剖分圆盘，它们恰好在 $`x`$ 相交。

后一情形的两个圆盘都不是退化的一条边；否则 $`u`$ 或 $`v`$ 在原图中的度就是 $`2`$。

如果两个小圆盘分别已有合格四着色，可以先置换颜色，使它们在 $`x`$ 上同色，再拼接。每一侧都使 $`x`$ 看到至少两种颜色。如果两侧合起来仍只有同一个二色集合 $`S`$，就在一侧置换颜色：固定 $`c(x)`$，把 $`S`$ 中一个不同于 $`c(x)`$ 的颜色，换成 $`S\cup\{c(x)\}`$ 外的一种颜色。这样 $`x`$ 就看到至少三种颜色。

因此，在对边数归纳时，**总能先给 $`G-uv`$ 找到合格四着色**，包括删除后出现割点的情形。

## 三、归纳消去边界上的相邻同类顶点

现在对 $`G`$ 的边数作强归纳。

称度至少为 $`4`$ 的边界顶点为**高点**，度为 $`2`$ 或 $`3`$ 的边界顶点为**低点**。

### 情形 A：两个高点相邻

删除它们之间的边界边。由上一节和归纳假设，可以给删边后的图合格四着色。

两个端点删边后仍有度至少 $`3`$，因此已经各自看到三种颜色。恢复这条边不会破坏任何条件。此情形完成。

以后可假设，外圈上没有相邻高点。

### 先处理三角形外圈

如果三角形外圈上有度 $`2`$ 的顶点，则整个图就是 $`K_3`$，直接用三种不同颜色。

否则，三个边界顶点度都至少为 $`3`$。由于没有相邻高点，其中至少两个顶点度为 $`3`$。它们共享同一个内部邻点，而它们的度数迫使外三角形内部恰好由与该内部顶点相接的三个三角面组成。因此整个图是 $`K_4`$，给四个顶点不同颜色即可。

以下外圈长度至少为 $`4`$。

### 情形 B：相邻低点的度为 $`2,2`$

两个相邻度 $`2`$ 的边界顶点迫使整个图为 $`K_3`$，已处理。

### 情形 C：相邻低点的度为 $`2,3`$

沿外圈依次记为

``` math
a,\ u,\ v,\ b,
\qquad d(u)=2,\quad d(v)=3.
```

三角面条件给出

``` math
N(u)=\{a,v\},\qquad N(v)=\{a,u,b\},\qquad ab\in E(G).
```

删除 $`u`$，得到更小的圆盘。在其合格四着色中，$`v`$ 的邻点只有 $`a,b`$，故

``` math
A:=c(a)\ne c(b)=:B.
```

把另外两种颜色记为 $`C,D`$。

重新给 $`v`$ 选择 $`C,D`$ 中的一种，使 $`b`$ 仍合格。这总能做到：$`b`$ 的其他邻点包含颜色为 $`A`$ 的顶点 $`a`$，应用二选一补色事实即可。把选中的颜色记为 $`C`$，再给 $`u`$ 颜色 $`D`$。

于是：

- $`u`$ 看到 $`A,C`$；
- $`v`$ 看到 $`A,B,D`$；
- $`a`$ 看到 $`B,C,D`$；
- $`b`$ 仍合格；
- 其他顶点不受影响。

此情形完成。

### 情形 D：相邻低点的度为 $`3,3`$

沿外圈依次记为

``` math
a,\ u,\ v,\ b,
\qquad d(u)=d(v)=3.
```

设三角面 $`uvx`$ 位于边界边 $`uv`$ 内侧。则

``` math
N(u)=\{a,v,x\},\qquad N(v)=\{u,b,x\}.
```

这里 $`a,b,x`$ 两两不同，且 $`ax,bx`$ 都是边。

收缩边界边 $`uv`$ 为一个顶点 $`p`$，合并两条重合的 $`px`$。得到更小的简单三角剖分圆盘，且

这个操作在 $`x`$ 位于原外圈时同样有效：只消去三角面 $`uvx`$，外圈将 $`u,v`$ 替换为 $`p`$。

c(u)\in\{A,D\},\qquad c(v)\in\{B,D\},

## 四、处理高低交替的外圈

把外圈写为

``` math
a_1,\ell_1,a_2,\ell_2,\ldots,a_m,\ell_m,
```

下标按模 $`m`$ 计算，其中

``` math
d(a_i)\ge4,\qquad d(\ell_i)\in\{2,3\}.
```

这里 $`m\ge2`$。

记

``` math
H=\{a_1,\ldots,a_m\},\qquad L=\{\ell_1,\ldots,\ell_m\}.
```

若 $`d(\ell_i)=3`$，把它除 $`a_i,a_{i+1}`$ 外的第三个邻点记为 $`x_i`$，并令

``` math
\mathcal X=\{x_i:d(\ell_i)=3\}.
```

### 1. 低点之间没有弦

度 $`2`$ 的低点显然没有弦。

若两个度 $`3`$ 的低点 $`\ell,\ell'`$ 由弦相接，设 $`\ell`$ 的两个边界邻点为 $`a,b`$。三角面条件迫使 $`\ell'`$ 同时邻接 $`a,b`$。由于 $`\ell'`$ 也只有度 $`3`$，它的两个边界邻点也只能是 $`a,b`$。

于是外圈是

``` math
a,\ell,b,\ell',
```

内部恰好由三角面 $`a\ell\ell'`$、$`b\ell\ell'`$ 填满。这使 $`a,b`$ 的度为 $`2`$，与它们是高点矛盾。

所以 **$`L`$ 是独立集**，所有 $`x_i`$ 都在 $`V(G)\setminus L`$ 中。

### 2. 删除低点，得到核心

令

``` math
K=G-L.
```

这个图连通：每个被删低点的剩余邻点，在 $`K`$ 中仍由一条边或一条两边路径连接。删除的是外圈顶点，所以所有被删三角面都并入外面；其余有界面仍然是三角形。

$`K`$ 的外面边界可能经过重复顶点，但第一节的引理允许这种情况。其边界顶点集恰好为

``` math
B=H\cup\mathcal X.
```

称

``` math
H_0=H\setminus\mathcal X
```

中的顶点为普通高点。

普通高点 $`a_i`$ 恰好失去外圈上紧邻的两个低点。否则，它若还邻接另一个低点，就会是那个低点的第三邻点，从而属于 $`\mathcal X`$。

因此，普通高点 $`a_i`$ 在 $`K`$ 中的邻点可按顺序写为

``` math
z_1,\ldots,z_k,\qquad k=d_G(a_i)-2\ge2,
```

相邻两项与 $`a_i`$ 组成保留下来的三角面，而且 $`z_1,z_k`$ 都在 $`K`$ 的外面边界上。

特别地，若它后面的低点 $`\ell_i`$ 度为 $`3`$，则

``` math
z_k=x_i. \tag{1}
```

### 3. 构造辅助平面图并正常四着色

对 $`K`$ 应用第一节的引理，得到 $`P`$。

再对每个度为 $`3`$ 的低点 $`\ell_i`$，加入边

``` math
a_i a_{i+1}.
```

这条边可以画在刚刚删除的两个三角面

``` math
a_i\ell_i x_i,\qquad \ell_i a_{i+1}x_i
```

所占的区域内。不同低点的这些区域内部不相交，也不与引理中的翻边区域内部相交。

因此，所得辅助图仍然平面、无环；重复边可以保留或合并。由四色定理，它存在正常四着色 $`c`$。

这个着色在原来的 $`K`$-邻域上有以下性质：

- 每个 $`K`$ 的内部顶点看到至少三种颜色。
- 对每个普通高点 $`a`$，令
  ``` math
  S(a)=c(N_K(a)),
  ```
  则
  ``` math
  |S(a)|\ge2. \tag{2}
  ```
- 若 $`d(\ell_i)=2`$，则 $`a_i a_{i+1}`$ 是保留下来的边，所以
  ``` math
  c(a_i)\ne c(a_{i+1}). \tag{3}
  ```
- 若 $`d(\ell_i)=3`$，则 $`a_i,x_i,a_{i+1}`$ 在辅助图中形成三角形，所以这三个顶点颜色两两不同。 \tag{4}

现在只须给独立集 $`L`$ 补色。

### 4. 给度为 $`2`$ 的低点补色

对 $`d(\ell_i)=2`$：

- 如果 $`a_i\in H_0`$ 且 $`|S(a_i)|=2`$，给 $`\ell_i`$ 选一种不在 $`S(a_i)`$ 中的颜色。
- 否则任意选色。

由式 (3)，$`\ell_i`$ 自己已经看到两种邻居颜色；同时，如果前面的普通高点 $`a_i`$ 还缺第三种颜色，这一步就把它补上。

### 5. 给度为 $`3`$ 的低点补色

对 $`d(\ell_i)=3`$，记

``` math
A=c(a_i),\qquad B=c(a_{i+1}),\qquad C=c(x_i),
```

并令 $`D`$ 为第四种颜色。由式 (4)，$`A,B,C,D`$ 两两不同。

采用下面的规则：

``` math
c(\ell_i)=
\begin{cases}
A,& a_i\in H_0\ \text{且}\ S(a_i)=\{C,D\},\\[2mm]
D,&\text{其他情况}.
\end{cases} \tag{5}
```

我们分别验证普通高点和第三邻点。

**普通高点 $`a_i`$。**

如果它在 $`K`$ 中已经看到三种颜色，就无需处理。否则由式 (2)，它恰好看到两种颜色。

当其后低点 $`\ell_i`$ 度为 $`3`$ 时，$`C=c(x_i)\in S(a_i)`$。

- 若 $`D\notin S(a_i)`$，给 $`\ell_i`$ 颜色 $`D`$ 即补上第三色。
- 若 $`D\in S(a_i)`$，则 $`S(a_i)=\{C,D\}`$，规则 (5) 给 $`\ell_i`$ 颜色 $`A`$，同样补上第三色。

结合度 $`2`$ 低点的规则，每个普通高点均被其后面的低点满足。

**第三邻点 $`x_i`$。**

通常 $`c(\ell_i)=D`$，于是 $`x_i`$ 的三个原邻点

``` math
a_i,\ a_{i+1},\ \ell_i
```

颜色为 $`A,B,D`$，已经满足要求。

唯一例外是

``` math
a_i\in H_0,\qquad S(a_i)=\{C,D\},\qquad c(\ell_i)=A.
```

此时，由普通高点的邻点路径及式 (1)，$`x_i`$ 前面还有一个核心邻点 $`z`$，且

``` math
a_i z x_i
```

是 $`K`$ 中保留下来的三角面。因为 $`z\in N_K(a_i)`$，

``` math
c(z)\in S(a_i)=\{C,D\}.
```

所以 $`x_i`$ 的三个原邻点

``` math
a_i,\ a_{i+1},\ z
```

分别带有颜色

``` math
A,\ B,\ c(z),
```

仍然是三种不同颜色。

因此，**即使例外规则不给 $`x_i`$ 增加新颜色，它也已经从核心中看到了三种颜色。**

这个论证同样允许 $`x_i`$ 本身也是某个边界高点。

### 6. 验证全部顶点

现在所有顶点都已着色：

- 每个低点的全部邻点都在 $`K`$ 中，由式 (3)、(4) 已满足自身要求；
- 每个 $`K`$ 的内部顶点由内部着色引理满足；
- 每个普通高点由其后面的低点满足；
- 每个 $`\mathcal X`$ 中的顶点由上面的第三邻点验证满足。

这些类别覆盖 $`V(G)`$。因此高低交替情形也存在合格四着色，归纳完成。

``` math
\boxed{\forall v\in V(G),\quad |c(N_G(v))|\ge\min\{3,d_G(v)\}.}
\qquad\square
```

## 五、为什么四种颜色不能减少

取 $`G=K_4`$，以任意一个三角形作为外圈。

每个顶点的三个邻点必须两两异色。而 $`K_4`$ 中任意两个顶点，都是某个第三顶点的邻点，因此任意两个顶点都必须异色。故至少需要四种颜色。

所以本题的精确上界就是

``` math
\boxed{4}.
```

上述证明同时给出有限构造流程：进行边界删边、删点或收缩，递归着色；遇到高低交替外圈时，求内部最大匹配，消除阻塞，翻边并给辅助平面图正常四着色，最后按式 (5) 补回边界。所有恢复步骤都已逐点验证。

文献中的相应近三角剖分猜想见 Francis、Illickan、Jose、Rajendraprasad 的 Conjecture 1；这里的边界论证处理了题目要求的任意简单外圈。[arxiv.org](https://arxiv.org/pdf/2205.06464)
