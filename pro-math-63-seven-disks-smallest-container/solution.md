## 1. 对任意摆法成立的圆心角下界

设外圆圆心为 $`O`$，半径为 $`R`$，半径 $`i`$ 的小圆圆心为 $`C_i`$。

两个最大的圆给出

``` math
13\le |C_6C_7|
\le |OC_6|+|OC_7|
\le (R-6)+(R-7),
```

所以

``` math
R\ge13.
\tag{2}
```

为证明下界，反设存在 $`R<R_*`$ 的摆法。以下只考虑五个圆 $`3,4,5,6,7`$。

令

``` math
m_i=
\begin{cases}
7,&i=3,4,5,6,\\
6,&i=7.
\end{cases}
```

由不重叠条件和三角不等式，

``` math
|OC_i|+|OC_{m_i}|\ge i+m_i.
```

因此，若这些圆放在半径 $`T`$ 的同心外圆中，就有

``` math
\ell_i(T):=i+2m_i-T
\le |OC_i|
\le T-i=:u_i(T).
\tag{3}
```

我们可以分别取 $`T=R`$，或把容器同心扩大到

``` math
B=\frac{27}{2}=13.5
```

后取 $`T=B`$。后者给出特别简单的区间：

``` math
(\ell_3,\ell_4,\ell_5,\ell_6,\ell_7)
=\frac12(7,9,11,13,11),
```
``` math
(u_3,u_4,u_5,u_6,u_7)
=\frac12(21,19,17,15,13).
\tag{4}
```

这些下界全为正，故五条圆心射线都有定义。

设 $`\delta_{ij}\in[0,\pi]`$ 是射线 $`OC_i,OC_j`$ 的较小夹角，$`x=|OC_i|,\ y=|OC_j|`$。不重叠意味着

``` math
x^2+y^2-2xy\cos\delta_{ij}\ge(i+j)^2,
```

于是

``` math
\cos\delta_{ij}
\le
\Phi_{ij}(x,y)
:=
\frac{x^2+y^2-(i+j)^2}{2xy}.
\tag{5}
```

### 一个端点引理

函数 $`\Phi_{ij}`$ 在正矩形

``` math
[\ell_i,u_i]\times[\ell_j,u_j]
```

上的最大值一定在四个角之一取得。

证明只需固定 $`y`$，观察

``` math
2y\Phi_{ij}(x,y)
=x+\frac{y^2-(i+j)^2}{x}.
```

当分子中的常数非负时，这是凸函数；当该常数为负时，这是递增函数。因此最大值在 $`x`$ 的端点取得。再对 $`y`$ 使用同样的论证即可。

把式（4）的端点代入，得到下表。第二列是四个角上的最大值 $`c_{ij}`$，第三列选择了一个正有理数 $`q_{ij}`$，满足

``` math
q_{ij}^2\le\frac{1-c_{ij}}{1+c_{ij}}.
```

因此式（5）蕴含

``` math
\boxed{\delta_{ij}\ge2\arctan q_{ij}.}
\tag{6}
```

## 2. 五个大圆的周向次序被强制确定

按圆心射线绕 $`O`$ 的顺序排列若干圆。相邻射线之间的**有向角隙**之和是 $`2\pi`$，每个有向角隙都至少等于对应的较小夹角。

因此，一个可行循环次序必须满足

``` math
\sum_{\text{相邻圆对 }ij}\arctan q_{ij}\le\pi.
\tag{7}
```

以下用整数运算排除不满足它的次序。

若 $`q=p/d>0`$，则复数

``` math
d+\mathrm i p
```

的辐角是 $`\arctan q`$。将一个循环各边对应的这些复数相乘，就能由虚部符号判断半角和是否超过 $`\pi`$。

具体计算如下；最后一个圆与第一个圆之间的边也计入乘积。

**为什么负虚部足以排除？**

- 对四圆循环，四个因子的辐角都在 $`(0,\pi/2)`$，所以辐角之和在 $`(0,2\pi)`$。
- 对表中三个五圆循环，都没有 $`67`$ 这条边，其余 $`q_{ij}<\sqrt3`$。因此五个辐角之和在 $`(0,5\pi/3)`$。

在这些范围内，乘积虚部为负就说明辐角之和大于 $`\pi`$，与式（7）矛盾。这也排除了辐角多绕一圈所造成的歧义。

现在进行完整分类。

四个圆 $`4,5,6,7`$ 的循环次序，在旋转和反向等价下只有三种：

``` math
(7,6,5,4),\quad(7,6,4,5),\quad(7,5,6,4).
```

前两种已被排除，所以只能是

``` math
(7,5,6,4).
```

再把圆 $`3`$ 插入四个间隙。表中后三行分别排除了插入 $`5\!-\!6`$、$`6\!-\!4`$、$`4\!-\!7`$ 的可能。

所以，五个大圆的次序只能是

``` math
\boxed{(7,3,5,6,4)}
\tag{8}
```

或其反向。

这一步覆盖了全部周向次序。

## 3. 证明容器半径不能小于 $`R_*`$

现在对式（8）中的五条边，把角度下界加强到精确的 $`A_{ij}(R)`$。

改用实际半径 $`R`$ 的径向界

``` math
\ell_i=i+2m_i-R,\qquad u_i=R-i.
```

定义

``` math
S_{ij}(R)
=u_i\ell_i+(i+j)^2-u_j^2.
```

展开得

``` math
S_{ij}(R)
=
2\bigl[-R^2+(i+j+m_i)R+i(j-m_i)\bigr].
\tag{9}
```

对我们需要的五对圆，$`S_{ij}`$ 在 $`13\le R\le13.5`$ 上递减。在右端点 $`R=13.5`$，两个方向的最小值如下：

|-------------|---------------------------------------|

| $`37`$      | $`51/2`$                              |
| $`46`$      | $`117/2`$                             |
| $`47`$      | $`133/2`$                             |

全都严格为正。

另一方面，直接相减得到

``` math
\Phi_{ij}(u_i,y)-\Phi_{ij}(\ell_i,y)
=
\frac{u_i-\ell_i}{2y\ell_i u_i}
\bigl(\ell_i u_i+(i+j)^2-y^2\bigr).
\tag{10}
```

因为 $`y\le u_j`$，括号内至少为 $`S_{ij}(R)>0`$。所以在两个 $`x`$ 端点中，上端点给出的值更大或相等。对 $`y`$ 也一样。

结合端点引理，

``` math
\Phi_{ij}(x,y)
\le
\Phi_{ij}(u_i,u_j)
=
1-\frac{2ij}{(R-i)(R-j)}
=
\cos A_{ij}(R).
```

从而，对式（8）的每条边都有

``` math
\delta_{ij}\ge A_{ij}(R).
\tag{11}
```

五个有向角隙之和是 $`2\pi`$，于是

``` math
2\pi
\ge
A_{73}(R)+A_{35}(R)+A_{56}(R)+A_{64}(R)+A_{47}(R).
\tag{12}
```

每一个 $`A_{ij}(R)`$ 都随 $`R`$ 严格递减。若 $`R<R_*`$，式（12）的右侧就严格大于

``` math
A_{73}(R_*)+A_{35}(R_*)+A_{56}(R_*)+A_{64}(R_*)+A_{47}(R_*)
=2\pi,
```

矛盾。

因此已经证明

``` math
\boxed{R_{\min}\ge R_*.}
\tag{13}
```

## 4. 在半径 $`R_*`$ 内放入全部七个圆

以下给出精确构造，并检查全部非邻接圆对。

### 4.1 构造五个大圆

取外圆圆心为原点。在本节简写 $`A_{ij}=A_{ij}(R_*)`$，令

``` math
\begin{aligned}
\theta_7&=0,\\
\theta_3&=A_{73},\\
\theta_5&=A_{73}+A_{35},\\
\theta_6&=A_{73}+A_{35}+A_{56},\\
\theta_4&=A_{73}+A_{35}+A_{56}+A_{64}.
\end{aligned}
```

定义圆心

``` math
\boxed{
C_i=(R_*-i)(\cos\theta_i,\sin\theta_i),
\qquad i=3,4,5,6,7.
}
\tag{14}
```

五个圆都内切外圆，循环相邻的圆彼此外切。方程（1）保证最后从圆 $`4`$ 回到圆 $`7`$ 的角隙正好是 $`A_{47}`$。

还需验证非邻接圆不会重叠。

表中的半角下界同样适用于 $`A_{ij}(R_*)/2`$：这是因为 $`R_*<13.5`$，而 $`A_{ij}`$ 随容器半径递减。

五条核心边中，两个最小的有理半角正切下界是 $`4/9,2/3`$。任意两个非邻接圆之间，两个方向的弧都包含至少两条不同的核心边，所以它们的半角都至少为

``` math
\arctan\frac49+\arctan\frac23
=
\arctan\frac{30}{19}.
\tag{15}
```

除 $`67`$ 外，非邻接圆对只有

``` math
34,\quad36,\quad45,\quad57.
```

其所需角度均不超过 $`A_{57}`$。又因为 $`R_*>67/5`$，

``` math
\tan^2\frac{A_{57}}2
<
\frac{35}{(67/5)(67/5-12)}
=
\frac{875}{469}
<
\frac94.
```

因此

``` math
\frac{A_{57}}2
<
\arctan\frac32
<
\arctan\frac{30}{19}.
```

这四对圆全部严格分离。

对于圆 $`6,7`$，经圆 $`4`$ 的弧，其半角至少为

``` math
\arctan\frac{17}{24}+\arctan\frac{10}{11}
=
\arctan\frac{427}{94}
>
\arctan3.
```

而

``` math
\tan^2\frac{A_{67}}2
<
\frac{42}{(67/5)(67/5-13)}
=
\frac{525}{67}
<9,
```

所以这条弧足够大。

另一个方向，经圆 $`5,3`$ 的弧，其半角至少为

``` math
\arctan\frac{16}{17}+\arctan\frac{30}{19}
>
\frac{\pi}{2},
```

最后一个不等式来自

``` math
\frac{16}{17}\frac{30}{19}>1.
```

它也大于 $`A_{67}/2`$。

至此，五个大圆的所有圆对均已检查。

### 4.2 插入半径 $`2`$ 和 $`1`$ 的圆

仍由 $`R_*>67/5`$，直接平方比较可得

``` math
\tan\frac{A_{13}}2<\frac16,\qquad
\tan\frac{A_{15}}2<\frac14,
```
``` math
\tan\frac{A_{25}}2<\frac7{20},\qquad
\tan\frac{A_{26}}2<\frac5{12}.
```

利用正切加法公式，

``` math
\frac{A_{13}+A_{15}}2
<
\arctan\frac{10}{23}
<
\arctan\frac49
\le\frac{A_{35}}2,
```

以及

``` math
\frac{A_{25}+A_{26}}2
<
\arctan\frac{184}{205}
<
\arctan\frac{16}{17}
\le\frac{A_{56}}2.
```

即

``` math
\boxed{A_{13}+A_{15}<A_{35},\qquad
A_{25}+A_{26}<A_{56}.}
\tag{16}
```

因此可以先在圆 $`5,6`$ 之间放入圆 $`2`$，再在圆 $`3,5`$ 之间放入圆 $`1`$。具体取

``` math
\theta_2=\theta_5+A_{52},\qquad
\theta_1=\theta_3+A_{31},
```

并定义

``` math
\boxed{
C_2=(R_*-2)(\cos\theta_2,\sin\theta_2),\qquad
C_1=(R_*-1)(\cos\theta_1,\sin\theta_1).
}
\tag{17}
```

它们也内切外圆，且式（16）保证与所在间隙的两个端点圆不重叠。

最后检查与其他圆的关系。设新插入的圆半径为 $`s`$，另一个已有圆半径为 $`k`$。从新圆到圆 $`k`$ 的两个方向的角弧，各自都会经过所在间隙的一个端点圆 $`e`$。相应弧包含原来的 $`e`$ 到 $`k`$ 的弧段，其角度至少为 $`A_{ek}`$。

因为 $`e\ge s`$，而 $`A_{ak}(R_*)`$ 随 $`a`$ 增大而增大，所以

``` math
A_{ek}\ge A_{sk}.
```

故两个方向的弧都足够大，新圆与圆 $`k`$ 不重叠。这个论证也覆盖了两个小圆彼此之间的关系。

于是半径 $`R_*`$ 的容器确实容纳了全部七个圆：

``` math
R_{\min}\le R_*.
```

与式（13）合并，

``` math
\boxed{R_{\min}=R_*.}
```
